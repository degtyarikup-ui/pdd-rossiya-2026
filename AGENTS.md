# PDD workspace

Приложения самостоятельны: Россия — `apps/russia`, новая Беларусь — `apps/belarus`.
Общие UI-токены — `packages/pdd_ui`; проверки изоляции — `tools/multi_app`.
Сначала читать AGENTS.md выбранного приложения. Старые BY/RS не трогать.
План — `docs/architecture/multi-app-migration.md`.

Перед работой и коммитом — `git pull --rebase origin main`; коммитить только
свои проверенные файлы, сразу push. Не переписывать чужую историю/изменения.
AGENTS.md и CLAUDE.md синхронны. Репозиторий публичный: секреты/подписи не коммитить.
Сохранять российские идентификаторы, production-сервисы и пользовательские данные.

`flutter pub get` выполняется из корня workspace. Для российского приложения:
`cd apps/russia && flutter analyze && flutter test`. Старые `scripts/*.sh`
из корня — совместимые обёртки. Новые проверки/артефакты — output/ или scratch/.
Не создавать ссылки на исходники одной страны внутри другой. App assets только
своей страны; shared пакеты не зависят от приложений.

# Отзывы App Store, Google Play и RuStore в Telegram

Тема «Отзывы» в группе «Логи ПДД» обслуживается существующим ботом.
`StoreReviews` — отдельный Durable Object с сохранёнными отзывами, связями
Telegram message ID → store review ID, черновиками и очередью доставки.
Обновление приложения не требуется.

## Использование

1. Ответить текстом (Telegram Reply) на карточку отзыва.
2. Проверить предпросмотр и нажать «Опубликовать» или «Отменить».
3. Бот показывает принятие магазином и состояние публикации.

Создавать и подтверждать ответы могут администраторы группы. Подтверждение
привязано к автору черновика, группе, теме и сообщению предпросмотра.
Черновик действует 24 часа. Перед записью бот заново читает отзыв и ответ;
изменение оценки, текста или существующего ответа отменяет старый черновик.
Обычные сообщения вне ответа на карточку не публикуются.

В Google лимит ответа 350 символов, в RuStore — 500. В Telegram-интеграции
App Store лимит 3000, чтобы весь ответ помещался в одном предпросмотре.
Новый ответ заменяет существующий, о чём сообщает предпросмотр.

`/reviews` в теме показывает результат и время последней успешной проверки.
Из существующего пятиминутного cron опрос запускается не чаще раза в 9 минут
(обычно каждые 10 минут). Первый запуск импортирует доступную историю;
Google возвращает только отзывы, созданные/изменённые за последнюю неделю.
Звёзды без текста Google API не отдаёт. Последующие правки отзывов приходят
отдельными карточками. Ответы и статусы обновляют карточку.

## Настройка

- `STORE_REVIEWS_ENABLED="true"` включает интеграцию и отключает старый
  парсинг публичной страницы RuStore с отправкой в General.
- `STORE_REVIEW_CREDENTIALS` — JSON **секрет Cloudflare**, не файл в Git:
  `apple: {keyId, issuerId, appId, privateKey}`, `google: {client_email,
  private_key, package}`, `rustore: {keyId, privateKey, package, base}`.
- Apple использует ключ с Customer Support; Google — сервисный аккаунт с
  правом Reply to reviews; RuStore — ключ с методами отзывов и ответов.
  Package/App ID задаются серверным секретом, из Telegram не принимаются.
- Поддержка новых callback_query включена в существующий webhook и polling.
  Секрет проверки webhook сохраняется. Второй webhook для бота не создавать.
- При первом опросе DO создаёт тему «Отзывы», сохраняет её ID в собственной
  базе и `telegram_topics` KV и проверяет подключение callback_query.
- Админские маршруты: GET `/api/admin/reviews/status`, POST
  `/api/admin/reviews/setup`, `/api/admin/reviews/poll`. Требуют текущей
  админской авторизации; POST также защищён существующей CSRF-проверкой.

На 17.11.2026 новый `public-api-m.rustore.ru` возвращает из Cloudflare 526
(сертификат Russian Trusted CA). Прежний официальный
`https://public-api.rustore.ru` проходит стандартную TLS-проверку и поддерживает
авторизацию и отзывы; он используется в секрете `base`. Проверка сертификатов
не отключается. Если прежний домен перестанет работать, понадобится
серверный посредник с доверенной цепочкой RuStore, а не отключение TLS.

## Надёжность и проверка

Очередь карточек сохраняется до отправки в Telegram. Черновики и статус
публичной записи переживают рестарт. Повтор одного update и повторное нажатие
не создают ещё одну запись. При таймауте публикации запись автоматически
не повторяется: результат сверяется чтением из магазина. Ошибка одного
магазина не останавливает остальные. Предупреждения ограничены одним на
магазин за 6 часов. Завершённые черновики удаляются через 7 дней.

Проверки: `npm run test:reviews`, `npm run test:support`, тесты
`test-telegram-{auth,recovery,export}.mjs`, сборка `wrangler deploy --dry-run`.
Публичные ответы во время автоматического smoke-теста не отправлять.

Официальные API: [Apple](https://developer.apple.com/documentation/appstoreconnectapi/customer-review-responses),
[Google](https://developers.google.com/android-publisher/reply-to-reviews),
[RuStore](https://www.rustore.ru/help/work-with-rustore-api/api-feedback-process/feedback-process).

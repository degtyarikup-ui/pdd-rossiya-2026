# ПДД Беларусь — новое самостоятельное приложение

Тестовый фундамент, пока **не готов для обучения и публикации**. Отдельные Android,
iOS, web и pubspec; общий с Россией пакет цветов/размеров. Тема взята из текущей
России, шрифты Onest включены своей копией с OFL. Билетов, игры, аудио, backend,
аккаунтов, платежей и аналитики России здесь нет. Старые приложения не используются.

- `lib/domain/question_bank.dart` — проверяемый каталог с происхождением вопросов.
- `lib/domain/exam_session.dart` — отдельный BY-движок: 9+1, 15 минут, ≤1 ошибка;
  активация требует проверки актуального регламента и базы.
- `lib/presentation/` — главная, экзамен, разбор; светлая/тёмная тема.
- `lib/l10n/` — русский, белорусский, английский интерфейс.
- `assets/countries/by/catalog.json` — только проверенная база BY; сейчас пустая.
- `tools/validate_content.dart` — проверка схемы и готовности.
- `docs/content-sources.md` — результаты поиска и оставшиеся условия выпуска.

Из корня: `flutter pub get`, затем из этой папки `flutter gen-l10n`,
`flutter analyze`, `flutter test`. Сборки из корня:
`./scripts/build_belarus.sh apk|ios|web`. Отчёты лежат в workspace output/.
Временный ID обеих native-платформ: `online.pdddrive.belarus.next.dev`.
APK подписывается debug-ключом; iOS проверяется без подписи. Для сторов ещё
не созданы продукты/подпись/домены. Dev-интерфейс не предлагает обучение, пока
база не принята; синтетические вопросы существуют только в test/.

Перед выпуском необходимо: подтвердить источник/лицензию, сверить редакции ПДД
и регламента, импортировать полную базу с изображениями, проверить все вопросы,
добавить сохранение попыток/прогресса и восстановление после закрытия процесса,
согласовать production ID и сервисы, провести приёмку на устройстве.
`dart tools/validate_content.dart assets/countries/by/catalog.json --require-ready`
сейчас намеренно завершается ошибкой. Обычный dev build допускает пустую базу.

## Локальный просмотр импортированной базы

Проверенный снимок ПДД.by можно подключить уже во время сбора остальных вопросов.
Это отдельный режим просмотра с изображениями и раскрытием ответа, без экзамена,
оценки результата или повышения review-флагов. Он не означает полноту банка.

Из корня, на замороженном снимке вне Git:

```sh
scratch/pddby-tools-venv/bin/python apps/belarus/tools/import_pddby_preview.py scratch/pddby-preview-snapshot
cd apps/belarus
flutter run --dart-define=BY_CONTENT_PREVIEW=true
```

Импорт повторно проверяет ответы по сырым свидетельствам и SHA-256 изображений.
Локальные `assets/countries/by/preview_*` исключены из Git, исходный пустой
`catalog.json` не заменяется. Без define приложение открывает штатный каталог.
После импорта локальная BY-сборка включает эти ресурсы; российская — нет.
Для release workspace тестовые ресурсы необходимо убрать: `--require-ready`
проверяет их отсутствие. В публичный репозиторий банк и картинки не отправляются.
Изображения пока поддержаны только в режиме просмотра; загрузка их в обычный
экзаменационный каталог отклоняется, пока не реализована приёмка этого сценария.

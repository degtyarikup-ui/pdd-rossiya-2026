## Технические ориентиры для реализации

- Главный движок: `assets/game/game.js`. Начни с `buildStraightSegment`,
  `buildIntersectionSegment`, `buildRoundaboutSegment`, `addCornerFillet`,
  `addRibbon`, `addRibbonX`, `extrudedStrip`, `extrudedStripZ`,
  `replaceCorridorStrip`, `addDirtSurface`, фабрик изгиба и переезда.
  Поверхности строятся несколькими путями, одного изменения прямой недостаточно.
- У части `BufferGeometry` дорожных полос пока нет UV. Стандартные UV плоскости
  также не обеспечивают одинаковый масштаб текстуры на сегментах разной длины.
  Учитывай верх и боковые поверхности экструдированных тротуаров отдельно.
- `SEAM = 0.12` скрывает антиалиасинговые щели перекрытием поверхностей.
  Если рисунок перекрывающихся поверхностей различается, появится видимый шов
  или мерцание, даже при прежнем совпадении цвета.
- `registerRoadSegment` и другие функции местами распознают поверхность
  по `BRAND.asphalt`/`BRAND.sidewalk` и типу геометрии. Не ломай это при смене
  материалов: сохраняй либо явно переноси семантику поверхности.
  Важны `userData.surface`, `noRoad`, `containsRoad`, `roadMarking`,
  `material.userData.asphalt` и `material.userData.seasonal`.
- Система координат меняется после манёвров; нельзя просто подключить
  текущие мировые координаты к текстуре и считать это решением непрерывности.
  Проверь сохранность рисунка при переносе и повороте всего мира,
  а также его стык с новыми сегментами. Выбери и документируй привязку UV/фазы.
- Пример малого кеша: `assets/game/vehicle-materials.js`. Для дорожных карт
  нужен собственный понятный жизненный цикл; не присваивай им случайно признак
  `pddVehicleShared`. Адаптируй `disposeSegment`, чтобы общая карта не удалялась
  при удалении одного сегмента, а материалы и геометрии освобождались.
- Используется поставляемый в проекте `assets/game/three.min.js`,
  а не автоматически последняя версия Three.js. Проверь доступные API.
- `game-implementation.md` содержит исторические описания и результаты.
  Актуальные итоги последней проверки: 118 сценариев, 48 дорожных вопросов,
  35 ситуаций подряд, 26 манёвров и 22 подъезда в обоих режимах управления.
  Подробности — `game-review-fixes.md` и `game-texture-passes.md`.

## Локальная проверка

Из корня проекта можно поднять собственные серверы на свободных портах.
Не занимай порт лаборатории пользователя и не останавливай его процесс.

```bash
# Статика, корень репозитория. Выбери свободный порт; пример 8942.
python3 -m http.server 8942 --bind 127.0.0.1

# Отдельная лаборатория для тестов. Выбери свободный порт; пример 8941.
GAME_LAB_PORT=8941 python3 tools/game_lab/server.py
```

Тестам нужны Node.js, Playwright и Chrome; `NODE_PATH` указывает на установленный
Playwright. На машине предыдущего запуска он находился в
`/Users/sergei/.cache/codex-runtimes/codex-primary-runtime/dependencies/node/node_modules`.
На другом окружении найди соответствующие зависимости.

```bash
GAME_URL=http://127.0.0.1:8942 node tools/game-curved-road-test.cjs
GAME_URL=http://127.0.0.1:8942 node tools/game-road-review-test.cjs
GAME_URL=http://127.0.0.1:8942 node tools/game-engine-test.cjs
GAME_LAB_URL=http://127.0.0.1:8941 node tools/game-final-driving-test.cjs
GAME_LAB_URL=http://127.0.0.1:8941 node tools/game-vehicle-materials-test.cjs
GAME_LAB_URL=http://127.0.0.1:8941 node tools/game-transport-materials-test.cjs
```

Измерения GPU проводи отдельно от остальных работающих тестов, при одинаковых
камере, освещении и составе сцены. Укажи окружение и границы измерения:
время контрольной сцены на компьютере не является измерением FPS телефона.
Для галереи добавь снимки стыков и проездов, а не только отдельной плитки.

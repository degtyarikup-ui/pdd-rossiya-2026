# Дорожные знаки: официальный каталог

Сверка выполнена 24 октября 2026 года по приложению 1 к постановлению
Правительства РФ от 23.10.1993 № 1090, редакция от 28.08.2026.
Считается каждый действующий номер отдельно, включая таблички; варианты цвета,
скорости, названий населённых пунктов и других надписей внутри одного номера
не создают дополнительные записи.

Проверенный список номеров, официальных названий и соответствующих абзацев
сохранён в `tools/ru_content/official_signs.json`. Для каждой группы указаны URL
текста и графического приложения, SHA-256 исходного PDF. В разделе `images`
зафиксированы источники и SHA-256 добавленных SVG. Сетевые обращения для тестов
не нужны. При изменении ПДД сначала сверять текст **и графические приложения**:
групповые обозначения вроде «8.4.1–8.4.8» в тексте не перечисляют все подномера.

Основной источник: [приложение 1 к ПДД](https://www.consultant.ru/document/cons_doc_LAW_2709/ac7f7c6628d9b362a288243ce7da1c04b5d73fd2/).
Графика новых знаков — разделённые исходные векторы приложения или SVG с Wikimedia
Commons, визуально сверенные с графическими приложениями. Табличка 8.9.2
воспроизведена в векторе по официальному образцу, надпись переведена в контуры.

## Лента и озвучка

В каждом `signs_feed_manifest*.json` — те же 312 номеров, названия, изображения
и описания. Вопрос содержит четыре разных текстовых ответа; правильный ответ
совпадает с названием карточки. Все языки используют одинаковые ID.

У карточек с изменёнными ответами и новых/перенумерованных знаков ID заканчивается
на `_catalog2026`. Это исключает воспроизведение старого студийного файла с другим
набором ответов. До записи новой студийной озвучки работает существующий системный
TTS. Озвучку неизменённых вопросов и их ID сохраняем. Старые аудиофайлы не удалены:
они могут быть нужны ранее выпущенным сборкам и другим инструментам.

## Проверки

```bash
flutter test test/official_sign_catalog_test.dart
flutter test test/road_signs_engine_test.dart test/road_signs_stress_test.dart
flutter test test/localized_content_test.dart test/sign_folk_name_test.dart
```

`official_sign_catalog_test.dart` сравнивает полный набор номеров и русские
названия с независимым нормативным снимком, проверяет три языка, ленту и
раздельные картинки. Новые SVG загружаются рендерером Flutter. Для визуального
листа всех 43 новых SVG:

```bash
SIGN_CATALOG_PREVIEW=1 flutter test test/official_sign_catalog_test.dart
```

Лист сохраняется в `scratch/official-signs/flutter-preview.png`.

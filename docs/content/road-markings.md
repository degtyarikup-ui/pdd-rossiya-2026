# Дорожная разметка: официальный каталог

Сверка выполнена 24 октября 2026 года по приложению 2 к постановлению
Правительства РФ от 23.10.1993 № 1090 (редакция от 28.08.2026).

В приложении **48 отдельных номеров**: **39 горизонтальных** и **9 вертикальных**.
Разновидности 1.14.1–1.14.3, 1.16.1–1.16.3, 1.17.1–1.17.2 и 2.1.1–2.1.3
считаются отдельно. Варианты одного номера, например стрелы 1.18 или номера
дорог 1.22, находятся в одной карточке.

## Источники и формат

- [Горизонтальная разметка — приложение 2 к ПДД](https://www.consultant.ru/document/cons_doc_LAW_2709/8b4d779e30a40c4f48df8edd7c7d2e1a12e91d77/).
- [Вертикальная разметка — приложение 2 к ПДД](https://www.consultant.ru/document/cons_doc_LAW_2709/438c1121182de8bf8439dec90f602392ec7e9bf8/).
- [ГОСТ Р 51256-2018, таблица А.1](https://www.mos.ru/upload/documents/files/1106/GOSTR51256-2018TehnicheskiesredstvaorganizaciidorojnogodvijeniyaR_.pdf) — дополнительная сверка пиктограмм 1.24.4–1.24.7;
  для 1.24.6 используются пиктограммы велосипедной зоны, для 1.24.7 — красное
  поле с белым автомобилем, а не прежние «ЗОНА» и D.
- `tools/ru_content/official_markup.json` — независимый проверенный перечень,
  дословные определения и правила пересечения линий; URL текстов и графических
  приложений, SHA-256 PDF и изображений, происхождение новых SVG.
- `assets/countries/ru/questions/markup{,_en,_kk}.json` — данные приложения.
  Формат прежний: словарь групп со списками. Каждая запись содержит строковые
  поля `number`, `title`, `image`, `description`.
- `assets/countries/ru/images/markup/` — изображения. Однозначные исходные SVG
  сопоставлены номерам, общие рисунки 1.14.1/1.14.2, 1.24.1–1.24.3 и
  2.1.1–2.1.3 разделены по области просмотра. Недостающие схемы добавлены
  как обычные SVG по графическим образцам ПДД. Старые несвязанные иллюстрации
  не удалены, но больше не подменяют карточки нескольких разных номеров.

Фон асфальта в горизонтальных иллюстрациях — тёмный нейтральный `#3F4449`.
Это оформление подложки; нормативные цвета линий и символов сохранены.

Короткие заголовки — редакционные названия для навигации: в приложении 2
большинство видов перечислено только по номеру с определением. Русское
`description` состоит из определения и относящихся к нему дословных правил
пересечения линий, разделённых пустой строкой. В en/kk сохранены номера,
изображения и смысл нормативного текста.

Текст и графику нужно проверять вместе. Графический лист горизонтальной
разметки, приложенный к правовой базе, не показывает отдельно 1.24.6 и 1.24.7,
хотя оба номера прямо перечислены в действующем тексте. При подсчёте нельзя
ограничиваться подписями на этом листе.

## Использование в приложении

`QuestionsDataSource.loadMarkup()` передаёт все четыре поля. `SignsScreen`
ищет разметку также по номеру. `MarkupCategoryScreen` показывает изображение,
номер, заголовок и описание; изображение открывается для масштабирования по
нажатию. Путь изображений задаёт `CountryConfig.current.markupImagesDir`.

При пересборке переводов `tools/l10n/translate_content.py` сохраняет поля
`number` и `image` без перевода. Менять каталог сразу на ru/en/kk.

## Проверки и HTML-каталог

```bash
flutter test test/official_markup_catalog_test.dart test/questions_data_source_test.dart
MARKUP_CATALOG_PREVIEW=1 flutter test test/official_markup_catalog_test.dart
python3 tools/ru_content/export_catalog.py
```

Первый тест сверяет все номера с нормативным снимком, описания ru с дословными
определениями и правилами, структуру en/kk, наличие и отдельность изображений.
Проверяется загрузка всех 48 SVG рендерером Flutter, поиск номера, переход к
карточке и масштабирование на ru/en/kk при ширине 360 и 740 с текстом 200%.
Режим предпросмотра сохраняет лист изображений в
`scratch/official-markings/flutter-preview.png`.

Экспорт создаёт один автономный файл `output/pdd-signs-and-markings.html` со
встроенными изображениями: 312 знаков и 48 номеров разметки. В нём есть поиск,
категории, описания, увеличение и печать. Для другого пути:

```bash
python3 tools/ru_content/export_catalog.py --output output/catalog-review.html
```

Временный HTML и изображения предпросмотра не коммитятся.

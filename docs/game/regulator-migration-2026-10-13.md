# «Регулировщик»: завершение переноса на Godot — 13 октября 2026

Единственная точка входа — карточка в `GamesHubScreen` →
`GodotGame.playRegulator` → `regulator.tscn`. Без встроенного движка
приложение показывает локализованное сообщение о недоступности.
Старые `traffic-controller.html`, `traffic-controller.js`,
`traffic-controller-model.js` и Flutter-экран с WebView удалены.
Общие ресурсы `assets/game/` нужны «Перекрёстку» и сохранены.

## Поведение, сохранённое при переносе

- Блиц начинается после готовности сцены: 60 секунд, 5 жизней,
  16 сочетаний позы/стороны для автомобиля, пять вариантов ответа.
- Очки: 24 за первый ответ, +2 за шаг серии до 32; просмотр подсказки
  делит награду пополам до следующего вопроса. Ошибка сохраняет очки,
  сбрасывает серию и отнимает жизнь. Предел заезда — 1500.
  Flutter передаёт параметры из `GameEconomy` при запуске.
- После ответа показаны все разрешённые направления. Повторные нажатия
  заблокированы; подсказка закрывается. Ожидание: «Стоять» 700 мс,
  ошибка 1100 мс, движение — до завершения анимации +160 мс.
- Используется автомобиль и цвет из гаража. Манёвры завершаются за
  переходами, включают поворотники; повороты и разворот непрерывны.
- Щипок/трекпад: диапазон 0,4–2,6; во время движения обзор расширяется.
  Центр перспективы расположен над панелью ответов.
- Календарные сезоны, осенние листья, пешеходы на тротуарах,
  дневная сцена, длительная ясная погода и короткий дождь.
  `--season` и `--weather` позволяют проверить сезон/дождь/туман.
- Звук и вибрация следуют настройкам приложения; интерфейс учитывает
  тему, безопасные отступы и масштаб текста. Все строки экспортируются
  из ARB на ru/en/kk; результат можно прокрутить при крупном шрифте.
- Итоги: очки, решённые ситуации, точность, максимальная серия,
  предыдущий рекорд/новый рекорд, повторный старт и выход.

## Прогресс и выход

Каждый раунд получает ID сессии и порядковый номер. Итоги содержат список
раундов, поэтому повторный старт в Godot не стирает предыдущие достижения.
После ответа/окончания передаётся контрольная копия `run_finished`.
Выход возвращает все законченные раунды и текущий, если в нём были ответы.
Android сохраняет её и для системной кнопки «Назад»; веб возвращает её при
выходе из маршрута; iOS получает итог через обменный файл.
Flutter записывает каждый ID один раз, обновляет локальный рекорд/счётчик
решённых ситуаций, отправляет очки в общий рейтинг и синхронизирует прогресс.

## Проверки

```bash
godot --headless --path game_godot --script res://tests/regulator_check.gd
flutter analyze
flutter test
node tools/game_tests/mini-game-assets-test.cjs
# После веб-экспорта:
node tools/game_tests/regulator-smoke-test.cjs
```

Godot проверяет общую с Flutter матрицу из
`test/fixtures/traffic_controller_pdd_6_10.json`, анатомию поз,
непрерывность траекторий, игровую экономику, блокировку повторного ответа,
таймер, жизни, подсказки на всех языках, рестарт, результаты и декодирование
аргументов веб-версии. Flutter отдельно проверяет передачу настроек и
сохранение нескольких раундов с защитой от дублирования ID.

Для визуальной проверки интерфейса:

```bash
godot --path game_godot --resolution 320x568 \
  --script res://tests/regulator_ui_shot.gd -- \
  --out=/absolute/path/in/scratch/ui.png --screen-dp=320 \
  --lang=kk --text-scale=2 --dark
# --result — вместо вопроса показать итоговый экран
```

После изменения Godot пересобрать ресурсы целевой платформы командами
из `docs/game/README.md`. Изменение исходников само не обновляет установленный APK.

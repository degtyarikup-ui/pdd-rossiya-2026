# Знаки и светофоры: общий рендер и сохранённые точки установки

Знаки используют исходные SVG из `game_godot/signs/`; изображения и данные
ответов ПДД не переписываются. Квадратные формы сверены с приложением Д,
таблицей Д.5 [ГОСТ Р 52290-2024](https://normadocs.ru/gost_r_52290-2024),
который [действует с 01.01.2026](https://protect.gost.ru/gost/details/39b75217-29bd-492b-94f4-c0dccb72b299).
Секции, символы направлений и трамвайная схема сверены с
[ГОСТ Р 52282-2004](https://www.mos.ru/upload/documents/files/237/GOSTR52282-2004TehnicheskiesredstvaorganizaciidorojnogodvijeniyaSvetoforidorojnieTipii_Tekst.pdf).
Игровой масштаб знаков увеличен для читаемости; модели не являются
чертежами оборудования для установки на настоящей дороге.

## Знаки

`SignFace`/`sign_face.gdshader` рисуют лицевой рисунок и серую металлическую
оборотную сторону одной поверхностью. Круги, ромбы, прямоугольники,
треугольники и восьмиугольник получают аналитический контур со сглаживанием
через `fwidth`, работающим без MSAA. Переход прозрачности занимает примерно
один пиксель на краю; внутренняя часть щита непрозрачна. Крестообразные 1.3.1/2
сохраняют свой SVG-силуэт. Рисунок и надписи не просвечивают сзади.
У текстовых табличек `Label3D.double_sided=false`.
Лицевая сторона остаётся читаемой независимо от освещения, металл получает
обычное освещение. Знаки остаются вертикальными и сохраняют направление;
при виде сверху их видимая высота перспективно сокращается.

Размер SVG сам по себе не определяет форму щита: например, у 2.1 холст
100×86, а видимый ромб — около 80×80. Рендер сохраняет исходные пропорции,
не превращая все холсты в квадраты и не деформируя круги/треугольники.

Шесть каталоговых SVG содержат несколько самостоятельных образцов.
`signs/face_regions.json` выбирает первый полный щит у 5.15.2, 5.15.3,
5.15.4, 5.15.7, 5.23.1 и 5.24.1. Сам SVG остаётся прежним; используются область атласа и та же
текстура. 5.15.2/3/4 теперь показывают один квадратный щит, 5.15.7 — один
горизонтальный щит; у 5.23.1/5.24.1 показывается щит с названием населённого
пункта без соседнего образца 5.23.2/5.24.2. Эти шесть кодов отсутствовали среди 71 настроенного
знака при доработке. Для вариантов стрелок по полосам остаётся существующий
конструктор `laneDirections`, включая сочетания налево/прямо/направо.

Процедурная табличка 8.13 теперь квадратная, с одинаковым выносом ветвей во
всех направлениях. Толстые/тонкие дороги берутся из прежних `mainRoad`/`roads`.
Чтобы сохранить её центр и соседние щиты, прежняя высота остаётся, а ширина
уменьшается до неё (например, 2.4×1.8 → 1.8×1.8).

Размещение хранит прежнюю высоту слота отдельно от видимых размеров щита:
координаты/повороты объекта, `sign_board`, центры отдельных лиц, высота стойки,
вылет и высота консоли, зазоры и подъём светофора с табличками сохраняются.
При сравнении всех 71 настроенного крепления ни один такой параметр не изменился.

Одна поверхность вместо двух на картинку, общие `QuadMesh` и материалы,
8 сегментов на стойке и 6 на раскосе консоли. Текстуры 8.13 кешируются
с пределом 16, динамические материалы тоже с пределом 16.

Все 65 лиц пересобираются из исходных SVG-путей: видимый щит имеет около
256 пикселей по длинной стороне, mipmaps уменьшают мерцание вдали.
`tools/godot_export/build_sign_faces.gd` генерирует `face_layout.json` и
параметры `.svg.import`; сам рисунок не меняется, копий PNG нет.
Первоначальные размеры холста хранятся отдельно, поэтому округление размеров
нового растра не двигает крепления. Все 65 распакованных текстур с mipmaps
занимают 28 500 216 байт (27.2 MiB), проверяемый предел — 32 MiB. В игре
текстуры загружаются по мере использования, общий набор не загружается заранее.
Редактор также рисует SVG в canvas нужного размера и использует тот же контур.

```bash
godot --headless --path game_godot --script ../tools/godot_export/build_sign_faces.gd
godot --headless --path game_godot --import
```

## Светофоры

Источник пяти общих GLB — `tools/godot_export/build_signals.py` (Python 3,
стандартная библиотека): обычный, с правой/левой/прямой дополнительной секцией,
трамвайный. `tools/network/gen_tram_light.mjs` — совместимый вызов этого
генератора; он больше не копирует модели поверх файлов настроенных сцен.

```bash
python3 tools/godot_export/build_signals.py
godot --headless --path game_godot --import
```

`--output scratch/signals/generated` проверяет побайтовую воспроизводимость.
Упаковщик GLB общий с автомобилями; его прежние параметры по умолчанию
сохраняют автомобильные ресурсы побайтово.

`TrafficSignal` загружает общие сцены один раз. Корпус, стойка, экран и
козырьки объединены; апертуры имеют отдельные имена и дешёвый непрозрачный
шейдер. Основные центры сохранены: y=3.85/3.40/2.95, z=0.46. Размеры апертур
сохранены (радиус 0.21, у трамвайных 0.18); прежнее увеличение в 1.8 раза
к ним не применяется. Козырьки не закрывают рабочую поверхность.

Дополнительная секция показывает зелёную стрелку на чёрном фоне. Левая
секция находится слева при взгляде водителя на лицо; основная зелёная секция
получает контурные разрешённые направления. Состояние дополнительных
секций сохраняет прежнее включение; `arrowActive=false` выключает стрелку.

Трамвайные бело-лунные сигналы сохраняют схему трёх верхних и одного нижнего:
прямо — нижний/средний, налево — нижний/левый, направо — нижний/правый,
стоп — три верхних. Между апертурами остаётся видимый тёмный зазор.
Свечение меньше прежнего и направлено только вперёд. Оно не создаёт
цветных сигналов за задним металлическим экраном.

Жёлтый мигает с периодом 1 с; линза и свечение переключаются вместе.
Часы обновляет существующий `Junction`, без отдельного процесса на светофор;
нулевой шаг/пауза замораживают фазу. Состояния и логика ответов не меняются.

В «Разрули перекрёсток» используется та же геометрия с одним кешированным
профилем корпуса на тип. UV2 помечает стойку/основной корпус/дополнительную
секцию, чтобы сохранить прежние центры этой мини-игры (4.02/3.50/2.98,
z=0.42), стойку 4.6 м и боковую секцию ±0.62 м. Позиции и повороты у бордюра
остаются прежними. Новых дублирующих GLB нет.

| Основная игра | Было мешей / треугольников | Стало |
|---|---:|---:|
| Обычный светофор | 8 / 380 | 4 / 284 |
| С дополнительной секцией | 9 / 382 | 5 / 411 |
| Трамвайный | 24 / 940 | 8 / 572 |

Дополнительная секция получила круглый фон, корпус и контурные символы,
поэтому её треугольники немного выросли, а число мешей уменьшилось.
Бюджеты — 300/430/600 треугольников. Динамических источников света,
текстур светодиодов, интерьерной геометрии и новых изображений нет.

`Situation` сохраняет `pos/yaw/scale`, крепления и параметры задания и
использует общий ресурс вместо архивного `light_N.glb`. Архивы остаются для
редактора, эталонных проверок и неизвестного нового типа. Редактор получает
те же GLB/области знаков через каталог, включая серый оборот и мигание.

## Проверки

- `signals_models_check.gd`: 65 знаков, формы по видимой части рисунка,
  крепления, бюджеты/кеши, все основные состояния и шесть трамвайных сочетаний,
  пауза мигания, профиль мини-игры и центры всех 42 сохранённых светофоров.
- `signals_render_check.gd` (обычный рендер): реальные пиксели лицевой/обратной
  стороны, сглаженные контуры без MSAA, отсутствие цветного свечения сзади
  и раздельные трамвайные линзы.
- `sign_mount_check.gd`, `lane_sign_check.gd` и соответствующие JS-проверки:
  общая стойка, консоль, два щита, 42 сочетания направлений.
- `light_sign_sync_check.py`: экспорт креплений на копии сцены.
- `rules_check.gd`, `road_check.gd`, `crossroads_check.gd`, `regulator_check.gd`,
  `question_signals_check.gd`, `vehicle_lights_check.gd`, `signal_glow_check.gd`,
  `pause_actor_check.gd`, `streaming_check.gd`, `exit_loading_check.gd`.
- `flutter analyze`, `flutter test`; визуальная проверка редактора без сохранения сцен.

Снимки/эталонные сравнения — только `output/`/`scratch/`. Проверять крупный
и игровой кадр, фронт/тыл, повороты и низкое качество без теней.

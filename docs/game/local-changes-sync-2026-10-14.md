После `git fetch origin` архив можно просмотреть через `git show origin/<ветка>`.
Первый родитель архивного коммита — базовая версия, второй — сохранённый индекс,
третий (если есть) — дерево неотслеживаемых файлов. При необходимости восстановить
stash в другом checkout: `git stash store -m "Архив локальных правок" origin/<ветка>`.
Архивы проверены на запрещённые пути, известные форматы секретов и размер файлов
до публикации.

Перед синхронизацией также сохранены локальный Git bundle, бинарный diff и архив
изменённых файлов в игнорируемой папке `scratch/local-sync-2026-10-14/`.

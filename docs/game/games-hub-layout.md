# Обложки экрана «Игры»

Шесть обложек мини-игр перегенерированы 19 октября 2026 встроенным ImageGen
на основе прежних портретных изображений. Сохранены сюжеты, палитра и low-poly
стиль; объекты уменьшены внутри кадра, добавлен запас по краям и свободный низ
под название и рекорд. Квадратные файлы — 640 × 640 px, WebP quality 84–85.

## Перегенерация

Точные промпты и последовательность доработок каждой картинки сохранены в
[`tools/game_content/hub_square_prompts.json`](../../tools/game_content/hub_square_prompts.json).
Первый шаг каждой записи использует прежнюю обложку как edit reference;
следующие шаги — результат предыдущего. После генерации выполняются только
уменьшение до 640 × 640 и кодирование WebP с указанным качеством.

Текст, градиент, скругления и состояние «Скоро» рисует Flutter. В изображения
они не включены. Все недоступные карточки с отметкой «Скоро» отображаются
чёрно-белыми: общий фильтр обесцвечивает обложку, градиент и остальные слои
карточки. Доступные игры сохраняют цветные обложки.

Старый `prepare_hub_covers.cjs` воспроизводит портретные Figma-референсы и теперь
по умолчанию пишет в `output/games-hub/legacy-figma/`, чтобы не заменить
актуальные квадратные обложки. Перегенерированные PNG и промежуточные варианты
хранятся только в `output/`, `scratch/` или каталоге ImageGen; в сборке используются
оптимизированные WebP.

## Верстка и состояния

`games_hub_screen.dart` читает живые данные и открывает игры, рейтинг и существующий
пейвол. `games_hub_view.dart` отвечает за представление:

- «Живой город» закреплён широкой карточкой над штатной нижней навигацией и доступен
  без прокрутки. В широком горизонтальном окне карточка закреплена справа.
- Каталог мини-игр прокручивается отдельно от города: обычный телефон использует
  сетку из двух колонок (три на широком планшете). Сначала идут доступные «Это знак», «Регулировщик» и
  «Перекрёсток», затем «Знаки», «Нарушитель» и «Парковка» с отметкой «Скоро».
  Новые карточки пока обозначают место в каталоге; игровые механики и запуск для них
  ещё не подключены. Названия и состояния берутся из локализаций ru/en/kk.
- Большой системный текст: мини-игры переходят в одну колонку с прокруткой, без
  уменьшения размера текста. Карточки в одной колонке сохраняют высоту не меньше
  90% ширины, чтобы квадратные обложки не превращались в узкую полосу.
  Город остаётся закреплённым; короткий экран не заставляет
  прокручивать каталог для его запуска. В коротком горизонтальном окне с крупным
  текстом город получает больше ширины: видимыми остаются название и действие,
  вторичные метрики остаются в семантическом описании карточки.
- Нулевой рекорд: «Играть» вместо «Рекорд 0». Верхняя кнопка показывает **очки за неделю**
  и открывает рейтинг; рекорды на карточках остаются отдельными показателями.
- У карточки города одно действие на всю площадь, включая изображение, название,
  остаток заездов и таймер: открыть игру либо сразу открыть пейвол, если бесплатные
  заезды закончились. Выезжающего объяснения заездов и вложенных кнопок нет; для
  скринридера это одна кнопка с названием и текущим состоянием.
- Бесплатный доступ: остаток и таймер полного пополнения видны внутри карточки.
  При нуле заездов показываются ожидание и предложение безлимита; доступные мини-игры
  продолжают работать.
- Сохранённый заезд: «Продолжить заезд», пока есть бесплатный заезд или Премиум.
  При нулевом остатке без Премиума нажатие также открывает пейвол. Проверка сохранения
  использует тот же парсер, что и запуск Godot.
- Премиум: остаток, таймер и предложение покупки скрыты.

Запас **полностью восстанавливается через час после первого потраченного заезда**.
Последующие траты не сдвигают срок. Отсчёт и остаток сохраняются между запусками.

Для обложек используется общий image cache с ограничением декодирования до исходного
размера. Таймер обновляет только небольшую текстовую область; обложки отделены
`RepaintBoundary` и не перерисовываются каждую секунду.

## Проверка

```bash
flutter test test/games_hub_layout_test.dart test/games_hub_city_entry_test.dart \
  test/mini_games_flow_test.dart \
  test/game_runs_service_test.dart test/godot_garage_bridge_test.dart
GAMES_HUB_SCREENSHOTS=1 flutter test test/games_hub_layout_test.dart
```

Экспорт скриншотов сохраняется в `output/games-hub/`; там есть полный/частичный/пустой
запас, новичок, продолжение, Премиум, тёмная тема, компактный экран, планшет,
горизонтальное окно, крупный шрифт и локализации en/kk. Проверки размеров выполняются
также с нижней навигацией: город остаётся виден при прокрутке мини-игр, все его области
вызывают одно действие, нулевой остаток ведёт сразу в пейвол. Перед коммитом обязательны
общий анализатор и все Flutter-тесты.

## Пересборка

Скачать исходные PNG из Figma в локальный каталог, например `scratch/games-hub/figma/`:

| Исходный файл Figma | Результат |
|---|---|
| `imgImg2.png` | `hub_parking.webp` |
| `imgImg4.png` | `hub_signs.webp` |
| `imgImg1.png` | `hub_regulator.webp` |
| `imgImg3.png` | `hub_crossroads.webp` |
| `imgTelegramCloudDocument253776018970310543521.png` | `hub_city.webp` |

```bash
NODE_PATH=<каталог node_modules с sharp> node tools/game_content/prepare_hub_covers.cjs \
  --source-dir scratch/games-hub/figma
```

При необходимости `--output-dir` задаёт другой каталог для проверки. Скрипт фиксирует
кадрирование каждого изображения по макету, убирает прозрачность и выводит размер файлов.
Промежуточные файлы хранить в `scratch/` или `output/`.

## Верстка и состояния

`games_hub_screen.dart` читает живые данные и открывает игры, рейтинг, объяснение
заездов и существующий пейвол. `games_hub_view.dart` отвечает за представление:

- Обычный телефон: сетка 2×2 и широкая карточка города; высоты зависят от доступного
  места над штатной нижней навигацией. В широком окне город располагается справа.
- Большой системный текст: одна колонка с прокруткой, без уменьшения размера текста.
  На экстремально коротком экране прокрутка также сохраняет доступность всех действий.
- Нулевой рекорд: «Играть» вместо «Рекорд 0». Верхняя кнопка показывает **очки за неделю**
  и открывает рейтинг; рекорды на карточках остаются отдельными показателями.
- Бесплатный доступ: остаток и таймер полного пополнения. При нуле заездов появляются
  ожидание и предложение безлимита; остальные игры доступны.
- Сохранённый заезд: «Продолжить заезд», в том числе при нулевом остатке. Проверка
  использует тот же парсер сохранённого заезда, что и запуск Godot.
- Премиум: остаток, таймер и предложение покупки скрыты.
- «Парковка»: недоступная карточка с отметкой «Скоро».

Запас **полностью восстанавливается через час после первого потраченного заезда**.
Последующие траты не сдвигают срок. Отсчёт и остаток сохраняются между запусками,
все пустые ячейки в объяснении показывают один срок восстановления.

Для обложек используется общий image cache с ограничением декодирования до исходного
размера. Таймер обновляет только небольшую текстовую область; обложки отделены
`RepaintBoundary` и не перерисовываются каждую секунду.

## Проверка

```bash
flutter test test/games_hub_layout_test.dart test/mini_games_flow_test.dart \
  test/game_runs_service_test.dart test/godot_garage_bridge_test.dart
GAMES_HUB_SCREENSHOTS=1 flutter test test/games_hub_layout_test.dart
```

Экспорт скриншотов сохраняется в `output/games-hub/`; там есть полный/частичный/пустой
запас, новичок, продолжение, Премиум, тёмная тема, компактный экран, планшет,
горизонтальное окно, крупный шрифт и локализации en/kk. Проверки размеров выполняются
также с нижней навигацией. Перед коммитом обязательны общий анализатор и все Flutter-тесты.

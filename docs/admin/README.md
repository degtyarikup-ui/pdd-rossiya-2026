# Две админки

В проекте две разные панели. Их код и способы публикации различаются.

| Панель | Где открывается | Исходники | Назначение |
| --- | --- | --- | --- |
| Серверная | `/admin` у Worker | `server/install-notifier/` | Пользователи, Premium, аналитика, поддержка, публикации, настройки |
| Редактор блога | `http://127.0.0.1:8930/admin` | `tools/blog_admin/` | Статьи, изображения, предпросмотр и деплой сайта |

## Серверная панель

`worker.js` содержит исторический HTML/JS-шаблон в экранированных строках.
Новые изменения интерфейса вносить через модули, не ручным патчем этих строк.
`admin_ui.js` — оболочка, `admin_theme.js` — визуальная система;
`users_ui.js`, `analytics_ui.js`, `ai_ui.js`, `publications_ui.js`,
`blog_ui.js`, `social_ui.js`, `threads_ui.js`, `tasks_ui.js` — разделы.
Обработчики данных искать в соответствующих серверных модулях и маршрутах Worker.

План публикаций Worker не означает, что HTML статьи уже опубликован на сайте.
Даты плана отображаются по МСК; социальные очереди хранят время в UTC.
Доступ защищён секретом `ADMIN_PASSWORD`, пароля по умолчанию нет.
Проверки и эксплуатация — [сервер](../server/README.md) и
[README воркера](../../server/install-notifier/README.md).

## Локальный редактор блога

Запуск из корня: `./scripts/blog_admin.sh`.
`server.py` — локальный сервер, `admin.html` — редактор,
`generator.py` — сборка страниц, `gen_images.py` — генерация иллюстраций.
Редактируется `web_landing/ru/blog/<slug>/source.json`;
`published: false` исключает статью из публичных индексов.
Кнопка публикации запускает деплой лендинга и IndexNow.
Источники и генерируемые файлы — [контент](../content/README.md).

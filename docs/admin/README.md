# Две админки

В проекте две разные панели. Их код и способы публикации различаются.

| Панель | Где открывается | Исходники | Назначение |
| --- | --- | --- | --- |
| Серверная | `/admin` у Worker | `server/install-notifier/` | Пользователи, Premium, аналитика, поддержка, публикации, настройки |
| Редактор блога | `http://127.0.0.1:8930/admin` | `tools/blog_admin/` | Статьи, изображения, предпросмотр и деплой сайта |

## Серверная панель

`worker.js` содержит исторический HTML/JS-шаблон в экранированных строках.
Новые изменения интерфейса вносить через модули, не ручным патчем этих строк.
`admin_ui.js` — оболочка, `admin_theme.js` — визуальная система;
`users_ui.js`, `analytics_ui.js`, `ai_ui.js`, `publications_ui.js`,
`blog_ui.js`, `social_ui.js`, `threads_ui.js`, `tasks_ui.js`,
`economy_ui.js` — разделы.
Обработчики данных искать в соответствующих серверных модулях и маршрутах Worker.

План публикаций Worker не означает, что HTML статьи уже опубликован на сайте.
Даты плана отображаются по МСК; социальные очереди хранят время в UTC.
Доступ защищён секретом `ADMIN_PASSWORD`, пароля по умолчанию нет.
Проверки и эксплуатация — [сервер](../server/README.md) и
[README воркера](../../server/install-notifier/README.md).

## Локальный редактор блога

Запуск из корня: `./scripts/blog_admin.sh`.
`server.py` — локальный сервер, `admin.html` — редактор,
`generator.py` — сборка страниц, `gen_images.py` — генерация иллюстраций.
Редактируется `web_landing/ru/blog/<slug>/source.json`;
`published: false` исключает статью из публичных индексов.
Кнопка публикации запускает деплой лендинга и IndexNow.
Источники и генерируемые файлы — [контент](../content/README.md).

## Экономика

`economy_admin.js` хранит параметры и ручные записи в `economy_config` (KV).
`economy_ui.js` — сводка, расходы, доли и поступления; формы позволяют
добавлять, редактировать и удалять записи. Разовые, месячные и годовые расходы
имеют дату первого платежа и необязательную дату окончания; суммы — RUB/USD.
Повторы приходятся на календарную дату, 29–31 числа сокращаются до конца месяца.
Все даты и границы периодов — МСК.

- В поступления входят подтверждённые СБП и вручную внесённые фактические выплаты.
  Возвраты исключены; покупки в сторах показываются отдельной оценкой по тарифу
  и не увеличивают поступления повторно.
- Cloudflare и домен — бюджет, пропорциональный дням периода. Для учёта
  фактических списаний удалить бюджет кнопкой корзины и добавить расход с датой.
  Удаление встроенного бюджета выключает `cloudflareEnabled`/`domainEnabled`,
  убирает строку и расходы во всех периодах, сохраняя тариф. Вернуть бюджет
  можно флажком в параметрах. Пользовательские расходы удаляются из реестра.
  У каждой строки есть отдельная корзина с подтверждением удаления.
- Стоимость ИИ в KV накопительная: входит только в «Всё время», для месяца
  показана отдельно. «Всё время» начинает бюджет инфраструктуры с самой ранней
  известной записи, при пустой истории — с начала текущего месяца.
- Курс доллара и доли применяются ко всем периодам расчёта. Фонд развития
  вычитается из положительной прибыли до распределения; убыток не создаёт выплат.

Проверки из `server/install-notifier/`: `npm run test:economy`,
`npm run test:economy:ui` (нужны Playwright через `NODE_PATH` и Chrome;
путь браузера можно задать `CHROME_PATH`). Браузерный тест запускает настоящий
Worker с изолированным KV на localhost. `ECONOMY_UI_SCREENSHOTS=1` сохраняет
скриншоты в `output/economy-ui/`; `node test-economy-ui.mjs --serve` открывает
локальное превью с тестовыми данными, не подключаясь к рабочему хранилищу.

# Рабочая папка PDD

Единственный основной репозиторий находится в `main/` относительно этой
рабочей папки. Все команды Git, Flutter, сборки и изменения исходников выполнять
из `main/`. Перед работой прочитать `main/AGENTS.md` и карту нужной подсистемы.
Если этот файл открыт по пути внутри `main/docs/ops`, это шаблон инструкции
для внешней рабочей папки, а не дополнительный уровень `main/main`.

- `main/` — действующее приложение и общий код, единственный источник для
  новой Беларуси. План: `main/docs/architecture/multi-app-migration.md`.
- `archive/legacy-workspace/` — сохранённые уникальные материалы и старые
  рабочие копии. Не использовать их как основную версию и не удалять правки.
- `scratch/`, `claude-worktrees/` — рабочие копии и временные задачи; сначала
  проверять Git и активность. Не считать всю папку удаляемым кэшем.
- `output/` — локальные отчёты и результаты. Там могут быть нужные медиа.
- `build/` — ссылка на сборку основной версии; не дублировать её.

Для поиска сначала ограничивать путь `main/lib`, `main/tools`, `main/docs`
или нужной подсистемой. Не запускать рекурсивный поиск по всему workspace:
архив и scratch содержат старые копии тех же файлов.

Старые приложения и сайты Беларуси и Сербии не менять. Новую Беларусь делать
с нуля на основе текущей России. Секреты, подписи, прогресс и production-сервисы
сохранять. Не выполнять массовый git clean/reset и не удалять worktree по имени.

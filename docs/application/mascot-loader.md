# Векторный маскот загрузки

## Текущий этап: выбор статичной иллюстрации

До следующей работы над движением сначала выбираем один из трёх упрощённых
концептов. Они пока не перенесены в Flutter и не подключены к приложению:

- `assets/mascot/concepts/cone-a.svg` — мягкий объём, классические пропорции.
- `assets/mascot/concepts/cone-b.svg` — короткий округлый конус-игрушка.
- `assets/mascot/concepts/cone-c.svg` — графичный силуэт без градиентов.

```bash
python3 tools/mascot/build_concepts.py
# Открыть output/mascot/concepts.html: три иллюстрации крупно и в 96 px.
```

Предпросмотр статичный, со светлой, тёмной и синей подложками. Скрипт проверяет
отсутствие растров, фильтров и анимации, а ID переименовывает для независимого
совместного отображения SVG. Ни один из вариантов пока не выбран.

Ниже описан сохранённый эксперимент движения версии 2. После выбора новой
иллюстрации рисунок и движение нужно согласовать с выбранным концептом.

## Сохранённый эксперимент версии 2

Оранжевый конус перерисован в векторе по предоставленному растровому
референсу. Версия 2: усечённая округлая макушка, эллиптическая нижняя грань,
изогнутые белые полосы и компактные открытые ладони. Радиальные и линейные
градиенты, свет сверху слева, затемнённый правый край и контактная тень
дают вид объёмной игрушки. Растровых текстур, фильтров и размытия нет.

## Файлы и использование

- `assets/mascot/cone.svg` — редактируемый исходный рисунок, `viewBox 480×480`.
- `assets/mascot/cone-animated.svg` — переносимая SVG/CSS-анимация для просмотра
  в браузере; генерируется из исходника, вручную не менять.
- `lib/presentation/widgets/cone_mascot_loader.dart` — нативная анимация Flutter.
- Рисунок Flutter генерируется из того же SVG скриптом в `tools/mascot/`.

```dart
Center(
  child: ConeMascotLoader(
    size: 144,
  ),
)
```

Маскот пока подготовлен отдельно и не подключён ни к одному экрану приложения.
Рекомендуемый размер — 96–192 logical px. При будущем подключении передать
в `semanticsLabel` локализованную подпись загрузки из ru/en/kk.
Сам рисунок не содержит текста и подходит для светлой, тёмной и фирменной
синей подложки. Для цвета орбиты предусмотрен `activityColor`: например,
на синем фоне нужен светло-голубой, а в обычном UI используется акцент темы.

Это загрузчик внутри работающего Flutter UI. До `runApp` его показать нельзя;
нативная заставка Android/iOS и порядок запуска приложения не менялись.

## Движение

У персонажа и индикатора разные роли. Эллиптическая дорожка с бегущей дугой
и тремя объёмными огоньками непрерывно сообщает об активности: оборот за 1,6 с,
передняя половина рисуется поверх персонажа, задняя — за ним. Это неопределённая
загрузка: нет выдуманного процента или самопроизвольного перехода в «готово».

Бесшовная фраза персонажа длится 3,2 с: небольшое приседание, первый прыжок
до 20 единиц рисунка, мягкое приземление, затем второй прыжок меньшей силы.
Деформация тела до 3%, наклон до 2,6°. Ладони отстают примерно на 70 мс,
зрачки следят за огоньком, моргание короткое. После прыжков есть спокойные
паузы, но индикатор всё время движется.

При системном отключении анимаций остаётся статичная доброжелательная поза.
В скрытом приложении и под отключённым `TickerMode` контроллер останавливается.

`CustomPainter` получает `repaint` от одного контроллера, пути и краски
создаются заранее; перерисовывается только ограниченная область маскота
в `RepaintBoundary`. Новых зависимостей, WebView, видеодекодера или 3D-движка нет.
SVG в папке `assets/mascot/` — исходники дизайна, в `pubspec.yaml` они
не подключены и в Flutter asset bundle не попадают. Геометрия персонажа,
краски и градиенты кешируются; 24 сегмента светового хвоста и шейдер огоньков
создаются при создании painter, а не на каждом кадре.

## Просмотр и проверка

```bash
python3 tools/mascot/svg_to_flutter.py assets/mascot/cone.svg lib/presentation/widgets/cone_mascot_art.dart
dart format lib/presentation/widgets/cone_mascot_art.dart
python3 tools/mascot/build_preview.py
# Открыть output/mascot/preview.html: светлый/тёмный/синий фон, пауза, размеры.
flutter test --dart-define=CAPTURE_MASCOT=true test/cone_mascot_loader_test.dart
# Снимки фактической отрисовки Flutter — output/mascot/flutter-mascot*.png.
flutter analyze
flutter test
```

Переносимый SVG/CSS-просмотр и Flutter-виджет реализуют один рисунок и ритм
движения. SVG/CSS не проигрывается пакетом `flutter_svg`: в приложении
используется самостоятельный `CustomPainter`.

Исходный SVG занимает примерно 13,8 КБ, а анимированный браузерный SVG — 56,2 КБ
(около 10,9 КБ gzip, включая таблицы координат движения). Эти числа описывают файлы,
а не увеличение APK. Нативная геометрия и анимация — около 38 КБ исходного Dart:
Flutter использует скомпилированные пути. Точную прибавку, время кадра и память
можно измерить только сравнением release-сборок и profile на устройстве.
Автоматические тесты не заменяют такую проверку производительности.

## Основания для сценария

У [Apple](https://developer.apple.com/design/human-interface-guidelines/progress-indicators)
неопределённый индикатор означает продолжающийся процесс без оценки оставшегося
времени. Здесь эту роль выполняет непрерывная орбита, независимо от жестов конуса.
[Material Loading Indicator](https://github.com/material-components/material-components-android/blob/master/docs/components/LoadingIndicator.md)
использует заметные изменения формы и движения для короткого ожидания.
У [Duolingo](https://blog.duolingo.com/world-character-visemes/) отдельно
управляются позы, лицо и реакции персонажа; здесь тот же принцип разделения
применён к своему рисунку, без копирования чужого персонажа или внедрения Rive.

## Вариант с 3D

Настоящий 3D-конус возможен. Сам простой меш может быть маленьким; основная
дополнительная стоимость — проигрыватель, его запуск, память и GPU.
Ниже ориентиры для планирования, не измерения готовых файлов:

| Вариант | Возможный порядок размера графики | Особенности |
| --- | --- | --- |
| Текущий вектор с объёмными градиентами | Десятки КБ исходников | Встроенная отрисовка Flutter |
| Заранее отрендеренный 3D-ролик, 384–512 px | Примерно 0,2–2 МБ | Нужен декодер, прозрачность усложняет совместимость |
| Простая модель GLB с анимацией | Примерно 0,1–1 МБ | Runtime может дополнительно добавить мегабайты |

Для единственного загрузчика разумно оставить текущую векторную версию.
3D имеет больше смысла для интерактивного персонажа или внутри уже работающей
Godot-сцены; запускать Godot ради короткого ожидания Flutter не стоит.

Основания: [CustomPainter](https://api.flutter.dev/flutter/rendering/CustomPainter-class.html),
[производительность Flutter](https://docs.flutter.dev/perf/best-practices),
[формат glTF](https://www.khronos.org/gltf/).

# Векторный маскот загрузки

Оранжевый конус перерисован в векторе по предоставленному растровому
референсу. Прозрачный фон, голубые глаза, улыбка, белые полосы и перчатка
с большим пальцем вверх; объём создают градиенты и небольшие блики.
Растровых текстур, внешних ресурсов и размытия нет.

## Файлы и использование

- `assets/mascot/cone.svg` — редактируемый исходный рисунок, `viewBox 480×480`.
- `assets/mascot/cone-animated.svg` — переносимая SVG/CSS-анимация для просмотра
  в браузере; генерируется из исходника, вручную не менять.
- `lib/presentation/widgets/cone_mascot_loader.dart` — нативная анимация Flutter.
- Рисунок Flutter генерируется из того же SVG скриптом в `tools/mascot/`.

```dart
Center(
  child: ConeMascotLoader(
    size: 144,
  ),
)
```

Маскот пока подготовлен отдельно и не подключён ни к одному экрану приложения.
Рекомендуемый размер — 72–160 logical px. При будущем подключении передать
в `semanticsLabel` локализованную подпись загрузки из ru/en/kk.
Сам рисунок не содержит текста и подходит для светлой, тёмной и фирменной
синей подложки.

Это загрузчик внутри работающего Flutter UI. До `runApp` его показать нельзя;
нативная заставка Android/iOS и порядок запуска приложения не менялись.

## Движение

Один бесшовный цикл длится 6 секунд: спокойное вертикальное движение до 4 единиц
рисунка и покачивание до 0,7°, короткий жест перчаткой, моргание и подмигивание.
У каждого жеста есть пауза; персонаж не вращается и не подпрыгивает постоянно.
При системном отключении анимаций остаётся статичная доброжелательная поза.
В скрытом приложении и под отключённым `TickerMode` контроллер останавливается.

`CustomPainter` получает `repaint` от одного контроллера, пути и краски
создаются заранее; перерисовывается только ограниченная область маскота
в `RepaintBoundary`. Новых зависимостей, WebView, видеодекодера или 3D-движка нет.
SVG в папке `assets/mascot/` — исходники дизайна, в `pubspec.yaml` они
не подключены и в Flutter asset bundle не попадают.

## Просмотр и проверка

```bash
python3 tools/mascot/svg_to_flutter.py assets/mascot/cone.svg lib/presentation/widgets/cone_mascot_art.dart
dart format lib/presentation/widgets/cone_mascot_art.dart
python3 tools/mascot/build_preview.py
# Открыть output/mascot/preview.html: светлый/тёмный/синий фон, пауза, размеры.
flutter analyze
flutter test
```

Переносимый SVG/CSS-просмотр и Flutter-виджет реализуют один рисунок и ритм
движения. SVG/CSS не проигрывается пакетом `flutter_svg`: в приложении
используется самостоятельный `CustomPainter`.

Исходный SVG занимает примерно 8,6 КБ, а анимированный — примерно 10 КБ
(около 3 КБ gzip). Эти числа описывают файлы, а не увеличение APK:
Flutter использует скомпилированные пути. Точную прибавку, время кадра и память
можно измерить только сравнением release-сборок и profile на устройстве.
Автоматические тесты не заменяют такую проверку производительности.

## Вариант с 3D

Настоящий 3D-конус возможен. Сам простой меш может быть маленьким; основная
дополнительная стоимость — проигрыватель, его запуск, память и GPU.
Ниже ориентиры для планирования, не измерения готовых файлов:

| Вариант | Возможный порядок размера графики | Особенности |
| --- | --- | --- |
| Текущий вектор с объёмными градиентами | Десятки КБ исходников | Встроенная отрисовка Flutter |
| Заранее отрендеренный 3D-ролик, 384–512 px | Примерно 0,2–2 МБ | Нужен декодер, прозрачность усложняет совместимость |
| Простая модель GLB с анимацией | Примерно 0,1–1 МБ | Runtime может дополнительно добавить мегабайты |

Для единственного загрузчика разумно оставить текущую векторную версию.
3D имеет больше смысла для интерактивного персонажа или внутри уже работающей
Godot-сцены; запускать Godot ради короткого ожидания Flutter не стоит.

Основания: [CustomPainter](https://api.flutter.dev/flutter/rendering/CustomPainter-class.html),
[производительность Flutter](https://docs.flutter.dev/perf/best-practices),
[формат glTF](https://www.khronos.org/gltf/).

# Проверка перед Google Play — 21–22 сентября 2026

**Статус: локальные исправления и release-сборка подготовлены. Публиковать AAB пока рано: обновление требует нового backend, настройки проверки покупок и прохода через внутренний трек Google Play. Backend не развёрнут.**

## Исправления

- Тестовый вход требует debug-режим Flutter и GAME_DEBUG=true. В release/profile он отключён независимо от флагов. Сохранённый debug_tester не восстанавливается в production.
- Скрытое меню погоды/сезонов игры, NOTIF_TEST и SCREEN недоступны в release/profile. Release не подписывается debug-ключом при отсутствии ключа выпуска. Сборочный скрипт отказывается выпускать приложение без ключа backend.
- При неудачном удалении аккаунта вход сохраняется, чтобы можно было повторить запрос; приложение больше не сообщает об успешном удалении без подтверждения сервера.
- Окно входа прокручивается на малом экране; кнопки выдерживают большой шрифт. Строки вынесены в RU/SR ARB; пользователю не показываются внутренние исключения.
- Yandex OAuth принимает токен только с точного callback URI и совпадающим случайным state. Убраны выдуманные ID/email при неполном ответе провайдера; добавлен сетевой таймаут.
- Backend проверяет подписанные Google/Apple ID-токены (ключ, подпись, issuer, audience, срок), либо токен Яндекса и его client_id. Клиент получает сессию на 30 дней, хранит её в защищённом хранилище. Токены провайдеров не сохраняются. Android backup исключает защищённое хранилище.
- Облачный профиль, прогресс, удаление аккаунта и запись игровых очков требуют сессию владельца. Чужие userId отклоняются. Нет разрешения доступа при отсутствующем SHARED_SECRET. Выход/удаление отзывают сессии; удаление отзывает все сессии аккаунта.
- Однократно потребуется повторный вход после обновления: старый сохранённый профиль не является доказательством личности. Локальный учебный прогресс сохраняется. Старые версии без серверных сессий после обновления backend теряют доступ к облачным функциям; локальные учебные функции продолжают работать.
- Запоздавшие ответы синхронизации/оплаты после выхода не возвращают старый прогресс или Premium. Кэш Premium привязан к владельцу и сохраняется офлайн для того же подтверждённого аккаунта.
- Магазин не подставляет единственный доступный тариф вместо другого выбранного. Исправлены потеря быстрого результата покупки, повторная подписка на события и восстановление обработчика после недоступности магазина.
- Покупка и восстановление используют один серверный путь проверки. На клиенте больше нет выдачи 7/90 дней от текущей даты. Google Play проверяется через subscriptionsv2; App Store — через авторизованный App Store Server API. Срок берётся из ответа магазина. Состояния pending/hold/paused/expired не дают доступ; отменённая, но ещё оплаченная подписка сохраняет доступ до истечения срока.
- Один чек привязывается к одному аккаунту через атомарную операцию Durable Object. Новые Google Play покупки привязаны к хешу аккаунта. До открытия оплаты проверяется наличие серверной конфигурации. Неподтверждённая покупка не отмечается успешно доставленной.

## Проверки

- 147 Flutter-тестов пройдено, 1 прежний тест экспорта iOS-скриншотов намеренно пропущен. В том числе экзамены RU/BY/RS, прогресс, тренировка, лента, темы, уведомления, игровой контроллер и новые регрессии авторизации/оплаты.
- Новые регрессии: удаление debug-аккаунта; окно входа 320×480 при масштабе текста 200%; запрет подмены тарифа; отказ при неподтверждённой покупке; точный срок после повторного восстановления; выход во время проверки оплаты; сохранение Premium офлайн без передачи другому аккаунту.
- Анализатор Dart/Flutter: без замечаний на последнем завершённом прогоне.
- 12 серверных тестов безопасности: поддельная подпись, audience/issuer/expiry, чужой аккаунт, отозванные сессии, подмена Premium, повторное восстановление и конкурентное присвоение чека. Обычные серверные тесты и тесты админки пройдены.
- Игровой движок в headless Chrome: 67 сценариев, 35 последовательных проездов; JavaScript-ошибок нет. Дополнительный аудит: 28 проверок трафика, столкновений, восстановления и координат. Отдельно проверен запуск при нулевом размере WebView, изменение размеров и возврат.
- Проверены схема вопросов, правильные ответы и файлы изображений RU A/B, RU C/D, BY, RS. Повторные ID RU соответствуют одинаковым вопросам разных билетов с разными комментариями; ID не менялись.
- RU AAB 2.1.0+37 собран. Включён российский контент, BY/RS исключены. В libapp.so всех ABI отсутствуют маркеры signInDebug, GameDebugSheet, _openDebug, GAME_DEBUG, NOTIF_TEST, showTestReminder; это дополняет compile-time защиту kDebugMode.
- Дополнительно собран release-APK с GAME_DEBUG=true, NOTIF_TEST=true, SCREEN=game: отладочные методы отсутствуют во всех ABI. Отдельная сборка .audit установлена на Pixel 9 Pro XL. Визуальная проверка на устройстве не завершена: экран заблокирован. Исходное .dev приложение и его данные сохранены.
- Новый Worker успешно собран командой wrangler deploy --dry-run. Публикация не выполнялась.

## Что необходимо до выпуска

1. Настроить реквизиты проверки магазина на сервере. При чтении списка секретов Cloudflare GOOGLE_PLAY_SERVICE_ACCOUNT и APPLE_IAP_* не обнаружены. Без них новый клиент не запускает оплату. Инструкция: server/install-notifier/RELEASE_SETUP.md.
2. Развернуть проверенный Worker с новой привязкой PURCHASE_CLAIMS и миграцией v2, затем проверить реальный вход. Это несовместимое изменение облачной авторизации старых клиентов, требующее согласованного выпуска.
3. Внутренний трек Google Play: вход с Play App Signing, покупка, отмена, восстановление, продление/возврат, обновление поверх магазинной версии с сохранением прогресса. Google Play Console и реальные платежи не проверены. Подмена этих проверок локальными тестами недопустима.
4. versionCode оставлен 37. Если он уже загружен в Play Console, перед следующей загрузкой нужен новый код.
5. App Store: код проверки подготовлен, но реальная интеграция, настройки ключей и сборка iOS не проверены. Sandbox включается только серверной конфигурацией.

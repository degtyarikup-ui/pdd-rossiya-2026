# iOS 2.2.3 — исправление зависания игры

Версия исходников: `2.2.3+55`, bundle ID `ru.pdd.pddApp`.
Отдельная вкладка **«Игра» остаётся**. Раздел **«Игры» с мини-играми скрыт**;
`SCREEN=games` доступен только в debug-сборке.

## Исправления

- Подтверждён фикс `f29df99a`: после паузы первый кадр снова устанавливает
  `lastTime`, поэтому слабый профиль не остаётся в бесконечном пропуске кадров.
- Поздний `visibilitychange(hidden)` WKWebView больше не отменяет `setPaused(false)`
  от Flutter. Самостоятельный браузерный стенд продолжает учитывать видимость страницы.
- Тупиковые улицы используют существующую фабрику зданий вместо удалённой
  `createVillageHouse`; сцены больше не падают на этой ветке.
- Покупка и восстановление StoreKit сохраняют аккаунт инициатора. Смена входа
  до ответа магазина не привязывает транзакцию к новому аккаунту, включая
  `pending` и временный сбой потока покупок.
- Пустая тренировка не падает; выход не ждёт зависшего плагина озвучки.
- Скрипт IPA проверяет контент страны и подтверждение загрузки свежего архива.
  Успешный код Flutter после ошибки экспорта больше не считается успешной загрузкой.
  Также заранее создаётся каталог экспорта: `destination=upload` не создаёт
  локальную IPA, а Flutter после успешной загрузки пытается перечислить каталог.

## Проверки

- `flutter analyze --no-pub` — без замечаний.
- `flutter test --reporter expanded` в отдельной release-копии — 286 passed,
  1 штатно пропущенный тест экспорта скриншотов.
- `tools/game-frame-loop-test.cjs` — настоящий production `animate`, 60/120 FPS,
  слабый и адаптивный профили, ответ во время паузы, час в фоне, возврат управления,
  полный проезд `ticket_3_13`, ровно один `situation_cleared`, тупик и порядок
  событий видимости/паузы. Старая версия воспроизводит зависание.
- Навигация проверена: «Обучение»/«Игра»/«Лента»/«Профиль», без хаба «Игры».
- `tools/game-audit-test.cjs` — 28 проверок; `tools/game-robustness-test.cjs` — PASS.
- JavaScript-проверки выполнены в Chromium. Playwright WebKit на машине
  отсутствует; проверка на реальном iPhone отдельно не заменяется этими тестами.

## Сборка и App Store Connect

Сборка выполняется из чистой копии зафиксированного кода. Незаконченные правки
Game Lab из основной рабочей папки не включены.

```bash
EXTRA_DEFINES='--dart-define=ENABLE_REMOTE_PUSH=false' ./scripts/build.sh ru ipa
```

Новостные FCM-пуши выключены для этой iOS-сборки: APNs entitlement пока не настроен.
Локальные напоминания о тренировках остаются доступными.

Apple подтвердила загрузку **2.2.3 (55)**: `uploadEvent.state=success`,
`uploadEvent.title=Uploaded to Apple`, ошибок нет. В архиве проверены bundle ID,
версия, контент, совпадение упакованного `game.js` с проверенным исходником,
34 privacy manifest и наличие ключа приложения без вывода его значения.

Сборка установлена на физический iPhone 11. Запуск пока отклонён системой,
потому что телефон заблокирован; это ограничение проверки, а не crash приложения.
В App Store Connect создан черновик 2.2.3 с описанием исправлений.

# Вход в веб-версию

Продакшен: https://pdd-drive.ru/app/.

## Яндекс ID

Приложение «ПДД: билеты и экзамен», публичный client ID:
`94aa539db4634e44bf0b209d9a2205d2`.

В кабинете https://oauth.yandex.ru/ у владельца приложения в список
Redirect URI нужно добавить **точный** адрес:

```
https://pdd-drive.ru/app/yandex-auth.html
```

Существующий `ru.pdd.pddapp://oauth` сохранить: его использует мобильное
приложение. Не заменять client ID: сервер проверяет его, а премиум привязан
к существующим аккаунтам.

Ошибка Яндекса 400 «redirect_uri не совпадает с Callback URL» возникает
до выдачи токена и исправляется в настройках Яндекс ID, а не на воркере.
Официальная документация: https://yandex.ru/dev/id/doc/ru/register-auth.

Страница `web/yandex-auth.html` поставляется вместе с веб-сборкой.
Она передаёт результат только окну своего origin; приложение проверяет
случайный `state` перед использованием токена.

## Apple ID

Веб-плагин `sign_in_with_apple_web` возвращает `userIdentifier: null`.
`AuthService` берёт идентификатор из `sub` в identity token; воркер
проверяет подпись, issuer, audience и срок действия токена и возвращает
профиль с тем же идентификатором. Раньше пустой идентификатор мешал входу.

После изменения Dart-кода требуется веб-деплой:

```
./scripts/deploy_web.sh ru
```

Проверки: `test/auth_jwt_claim_test.dart` и `test/auth_login_recovery_test.dart`.
Полный вход проверяется на сайте с реальным аккаунтом владельца;
пароли и токены не сохранять в выводе диагностики.

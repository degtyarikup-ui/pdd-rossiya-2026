## Совместимость

- Старые сборки сохраняют вход, покупки, Premium и основную работу.
- Старое чтение поддержки с ключом приложения получает пустую историю и
  requiresUpdate: true. Неавторизованная приватная переписка не раскрывается.
  Старые гостевые идентификаторы без отдельного секрета не мигрируют в новую историю.
- Старые/офлайн-заезды продолжают играть локально, но без подтверждённой
  онлайн-регистрации не увеличивают серверный рейтинг.
- GitHub Pages сохраняет pdd-drive.ru как origin и старый рабочий адрес.
  Не менять его CNAME на .app: это создаст цикл проксирования.
- Старые OAuth return URI и Google origin сохранены; Apple callback выбирает
  один из двух фиксированных адресов по формату state, а не по произвольному URL.
- API api.pdd-drive.app, идентификаторы приложений и аккаунтов не меняются.

одно правило всё ещё превысило таймаут на большом сгенерированном файле. Мост Godot переписан на статические именованные операции без eval,
чтобы игра работала с CSP без unsafe-eval. Нативные публикации выполняет владелец.

## Остаточные ограничения

Бюджет рейтинга закрывает быстрое массовое начисление из исходного PoC,
но не доказывает участие человека. Перед автоматической выдачей ценных призов
нужны серверная проверка последовательности ответов и отдельная защита от ботов.
Переходные режимы AI/Apple для выпущенных клиентов сохраняют прежние сроки;
их не продлевали. Исторический пароль не принимается активным сервером.
Переписка в операторском Telegram имеет отдельный жизненный цикл и не
удаляется из самого Telegram автоматически при удалении аккаунта.
Для старого app.pdd-drive.ru запрошен повторный выпуск сертификата GitHub;
результат внешнего CA проверяется отдельно, обход проверки TLS не применяется.

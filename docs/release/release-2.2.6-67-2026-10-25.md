## Сборки

Google Play: `scripts/build.sh ru aab`, `STORE=play`.
RuStore: `scripts/build.sh ru rustore-apk`, `STORE=rustore`.
App Store Connect: `scripts/build.sh ru ipa` с подтверждением загрузки
из метаданных свежего Xcode-архива.

Магазинные сборки используют production package ID и ключ подписи,
без dev-суффикса и подмены региона. Игра заново экспортируется для каждой платформы.
Android-артефакты предназначены для ручной загрузки владельцем из папки релиза
на рабочем столе; при оформлении выпуска — автоматическая публикация после одобрения.

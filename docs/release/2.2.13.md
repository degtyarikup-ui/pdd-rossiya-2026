# Выпуск 2.2.13 (76), 08.11.2026

Продолжение исправления [ошибок 08.11](../ops/incident-2026-11-08.md)
после новой выгрузки с событиями на 2.2.12+75.

Устранена потеря поздних успешных ответов Google Play, обмена сессией входа
и проверки маршрута Telegram. Ожидание остаётся ограниченным; закрытая
попытка входа или заменённый запрос магазина не применяют устаревшие ответы.
Поздний каталог обновляет открытый экран покупки, а после полностью зависшего
цикла можно повторить загрузку. Сервер получил безопасную метку начала
обмена сессией для сопоставления с завершением.

Проверка чеков, принадлежность покупок, сроки Premium, ID товаров
и правила доступности способов оплаты не менялись.

## Проверки

- `flutter analyze` — без замечаний; полный Flutter: 1205 passed, 4 skipped.
- Сервер: `npm test` и `npm run test:security` — успешно, 468 security tests.
- Целевые проверки: 48 входа и повторов сети, 15 транспорта Telegram,
  23 загрузки каталога, восстановления и интерфейса покупки.
- Потеря позднего ответа воспроизведена на прежнем коде отдельно для
  каталога магазина, обмена сессией и проверки маршрута Telegram.
- Проверены отмена входа, предел ожидания, Retry-After, поздний ответ старой
  загрузки, восстановление после зависшего SDK и обновление открытого экрана.

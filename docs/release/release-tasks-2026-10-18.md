# Задачи перед релизом — 18 октября 2026

Рекомендация: релиз пока не выпускать. P1 ниже — открытые блокеры; Gate — обязательная проверка финального артефакта или решение по функции.

## R01 · P1 · Сохранность оплаченного Премиума

- [ ] Один атомарный путь записи аккаунта для callback, sync, IAP, admin и refresh; восстановление подтверждённых заказов без ledger.
- Платформы: Все платформы. Доказательство: BE-PAY-RACE.
- Приёмка: Конкурентные sync+оплата и две оплаты не теряют срок; retry не удваивает дни; сбой между записями сам восстанавливается.

## R02 · P1 · Проверка Google OAuth audience

- [ ] Настроить настоящие Android OAuth Client IDs и закрывать доступ при отсутствии allowlist.
- Платформы: Android / backend. Доказательство: BE-GOOGLE-AUD.
- Приёмка: Токен другого OAuth приложения отклонён; наши Google входы на Play и RuStore успешны; неверный конфиг fail-closed.

## R03 · P1 · Владелец покупки после перезапуска

- [ ] Стабильный UUID appAccountToken, проверка сервером и безопасная политика старых чеков.
- Платформы: iOS. Доказательство: BE-IOS-OWNER.
- Приёмка: A покупает → kill → вход B → StoreKit replay не выдаёт покупку B; A получает свой доступ; sandbox проверен.

## R04 · P1 · Экзамен по тематическим блокам

- [ ] Формировать четыре целых блока нужных групп; дополнительные пятёрки той же группы ошибки; сохранять group identity.
- Платформы: Все платформы. Доказательство: CLIENT-03.
- Приёмка: Реальные A/B и C/D + resume + две ошибки одной группы + ошибки в разных группах + доп. ошибка покрыты тестами.

## R05 · P1 · Серверная квота и доступ к ИИ

- [ ] Проверять сессию/права на сервере; ограничить расходы на аккаунт/установку/IP атомарной квотой.
- Платформы: Backend. Доказательство: BE-AI-QUOTA.
- Приёмка: Извлечённого app key недостаточно для безлимитного свободного чата; лимит выдерживает параллельные запросы.

## R06 · P1 · Отзыв Sign in with Apple при удалении

- [ ] Хранить необходимые данные безопасно и вызывать официальный revoke при удалении Apple-аккаунта.
- Платформы: iOS / backend. Доказательство: BE-APPLE-DELETE.
- Приёмка: Удаление отзывает Apple grant; серверная учётка и связанные данные удалены по определённой политике.

## R07 · P1 · Актуальность текста ПДД

- Приёмка: 2.1.1 соответствует официальной норме; parser check проходит; переводы/ссылки актуализированы. Первичный текст обязателен.

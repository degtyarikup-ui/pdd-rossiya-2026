# Переход к самостоятельным приложениям России и Беларуси

Дата: 2026-11-08. Базовый коммит: `8ad9157871ffbd2851970b7a7e4b3e2737691d69`.

## Решение и ограничения

Один репозиторий, отдельные Flutter-приложения стран и небольшие локальные
общие пакеты. Россия — ведущий продукт. Новая Беларусь создаётся с нуля на
основе текущего российского приложения. Старые приложения и сайты Беларуси
и Сербии не менять, не восстанавливать и не использовать как основу миграции.
Сербия не входит в план. США — возможное будущее приложение, без реализации сейчас.

Самостоятельность означает собственные pubspec, native projects, идентификаторы,
контент, экзамен, настройки сервисов, сборки и релизы. Один репозиторий не
означает общую серверную базу или общую подписку. Общий пакет не импортирует
приложение; приложения не импортируют друг друга.

Нельзя менять российские applicationId/bundle ID, подпись, магазинные продукты,
OAuth, push, backend, ключи сохранённого прогресса и форматы данных ради переноса.
Контент и ресурсы других стран не должны попадать в артефакты России.
Обещать отсутствие регрессий только по анализатору нельзя: перед релизом нужны
нативные сборки и проверка обновления поверх прежней dev-версии.

## Целевая структура

```text
apps/russia/           # pubspec, lib, test, assets, android, ios, web
apps/belarus/          # отдельное приложение, новые контент и настройки
packages/pdd_ui/       # общие токены, затем проверенные общие виджеты
scripts/               # совместимые команды сборки и проверки
apps/russia/server/    # российский backend; новый BY — изолированно
```

Точное размещение игры, генераторов и серверов решается отдельными этапами.
Не переносить все файлы одновременно и не создавать симлинки для имитации
двух приложений. Сначала выделяется общий код, затем переносится Россия.

## Откат и работа вдвоём

Каждый законченный этап — небольшой проверенный коммит и push по AGENTS.md.
При провале обязательной проверки следующий этап не начинать. Чужие правки
не откатывать. Откат своего этапа — отдельный revert-коммит, без reset/force push.
До публикации достаточно возврата к предыдущему исходному состоянию;
после публикации исправление проходит обычный выпуск новой версии.
Миграции production-данных в текущем этапе нет.

## Проверка артефактов на первом этапе

```bash
python3 -m unittest tools.multi_app.test_check_artifact
python3 tools/multi_app/check_artifact.py path/to/app.apk --country ru
python3 tools/multi_app/check_artifact.py path/to/app.aab --country ru
python3 tools/multi_app/check_artifact.py path/to/app.ipa --country ru
python3 tools/multi_app/check_artifact.py build/web --country ru
```

Команда возвращает ошибку при отсутствии контента целевой страны или наличии
явных путей другой страны. Отчёт содержит 20 самых тяжёлых файлов и суммарный
несжатый размер. Она не доказывает изоляцию безымянного аудио, вложенных архивов
и Godot pack: это остаётся задачей этапа 2. Существующий APK проверен как
пример старого артефакта, а не как сборка новых исходников.

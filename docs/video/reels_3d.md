# 3D-рилсы «Решишь за 3 секунды?»

Low-poly сцены в Godot (`game_godot/videos/`), вертикаль 1080×1920, 30 fps, 20–25 с.
Зритель — водитель **красной машины**, остальные машины белые.

## Формат (монтаж)

| Время | План | Звук |
|---|---|---|
| 0–4.8 | Погоня: камера за красной машиной, та подъезжает к стоп-линии | реплика 1: «Вы — в красной машине…» |
| 4.8–7 | Крупный план подсказки (инспектор/знак), ¾ ракурс | тишина |
| 7–11.6 | Вид сверху + карточка вопроса, полоска 3-секундного отсчёта | реплика 2 — вопрос, 3 тика |
| 11.6–15.6 | Ответ: зелёная/красная плашка, снова подсказка крупно | звонок, реплика 3 — ответ + пункт ПДД |
| 15.6–21 | Погоня: машина выполняет манёвр | — |
| 21–23 | Финальная карточка: «ПДД Россия 2026», pdd-drive.ru | — |

Правила стиля: на экране только вопрос и одно слово ответа, всё остальное говорит голос.
Цвета из `AppColors` (акцент 0574F8, зелёный 2BC280), шрифт Onest. Музыки нет.
Пояснение должно совпадать с ПДД и с `scripts/regulator_rules.gd`.

## Сборка

```bash
# кадры (окно и Movie Maker ограничены размером экрана, поэтому SubViewport)
godot --path game_godot --script res://videos/render_video.gd -- \
  --scene=res://videos/reel_turn_right.tscn --seconds=23 --out=$PWD/output/video3d/reel
# превью отдельных моментов: добавить --at=1,5.5,8
```

Озвучка — Gemini TTS, голос `Algenib` (как в `tools/signs_reel`). Если нет файла ADC,
передать `Credentials(gcloud auth print-access-token)` в `genai.Client`. Тишину по краям
срезать `silenceremove`, затем свести ffmpeg: `adelay` по таблице выше, `loudnorm=I=-14`.
Готовое — в `output/video3d/` (не в git).

Новый ролик = новый `reel_<тема>.gd`, наследник `intersection_scene.gd`: свои
константы времени, путь машины (`_pose`) и `set_time(t)`.

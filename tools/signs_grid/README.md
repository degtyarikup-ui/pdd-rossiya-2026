# Тесты с сеткой карточек

Общий план 3×3 → наезд на каждую карточку → ровно 3 секунды на ответ →
зелёная подсветка и голос → общий план со всеми ответами. 1080×1920, 30 fps,
Algenib с быстрым живым стилем, тихое тиканье и сигнал раскрытия ответа.
Длительность ограничена 58 секундами. Каждая реплика расшифровывается и
сверяется с текстом; длины аудио и видео проверяются после рендера.

## Регулировщик с иллюстрациями

Утверждённый лист персонажа — `assets/regulator-poses.png`. Это **исходник**,
не удалять вместе с результатами рендера. Девять иллюстраций с одинаковой
внешностью сгенерированы imagegen; у последней исправлена направленная
вперёд рука при виде со спины. При замене листа заново проверить все жесты,
анатомическую правую руку и прямоугольники обрезки.

`regulator_illustrated.json` сохраняет порядок поз, их координаты на листе,
положение относительно водителя легкового автомобиля, ответы и реплики.
Ответы сверены с п. 6.10 ПДД РФ; проверяется только сигнал регулировщика.

```bash
python3 -m tools.signs_grid.regulator_illustrated --preview
python3 -m tools.signs_grid.regulator_illustrated
```

Видео копируется в `~/Desktop/Тест — регулировщик.mp4`, рабочие файлы и превью
идут в `output/signs_grid/regulator_illustrated/`. Общий рендерер — `video.py`,
вёрстка — `overview.py`. Для озвучки используется обычный проект ADC, а при
отсутствии ADC — активный проект и авторизация gcloud. Секреты в исходниках
не сохраняются.

## Тест по знакам

Исторический план восьми выпусков без повторов — `episodes.json`.
Первый выпуск был отобран вручную, остальные — `series.py`.

```bash
python3 -m tools.signs_grid.video --episode 1
python3 -m tools.signs_grid.video --all
```

Изображения и названия берутся из `signs.json`, поэтому после обновления
официального каталога исторические формулировки в плане надо сверить с новой
базой перед повторной сборкой.

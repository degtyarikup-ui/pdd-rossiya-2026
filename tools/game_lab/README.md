# Просмотр дорожных ситуаций

Запуск из корня проекта: `./scripts/game_lab.sh`.
Открыть http://127.0.0.1:8940/ — только на этом компьютере.

Слева — каталог и поиск по номеру билета или тексту. В центре — настоящая
игровая сцена из `assets/game`, справа — исходная картинка, вопрос, варианты
ответов и пояснение из базы RU A/B. По умолчанию показаны 166 используемых
игровых вопросов и семь процедурных дорожных событий. Фильтр «Все» также
показывает 35 исключённых сцен; их причина исключения указана справа.
Процедурные события не привязаны к билету и явно помечены.

- Стрелки сверху перебирают текущий отфильтрованный список.
- «Карточка на телефоне» моделирует площадь, которую занимают ответы; это
  вспомогательный HTML-предпросмотр, фактическую Flutter-типографику проверяет
  `test/game_controller_test.dart`.
- Тёмная тема, погода, сезон, размеры экрана и масштаб позволяют увидеть
  визуальные проблемы. Свободная камера вращается мышью, Shift перетаскивает,
  колесо меняет масштаб.
- В режиме «Осмотр» машины остаются на исходных позициях. В режиме «Езда»
  можно пройти сцену, выбрав ответ справа и управляя клавишами W/A/S/D.
- «Да» / «Нет» и заметка сохраняются в `tools/game_lab/review.json`.
  Заметка записывается при выходе из поля (например, после клика по следующей
  сцене). Фильтр 📝 показывает все непустые заметки, в том числе при «Да».
  «Отчёт» скачивает JSON с отмеченными сценами, их исходными question ID и
  заметками для дальнейшего исправления.
- Клик по исходной картинке открывает её крупно.
- После обновления страницы фильтр «Изменено» показывает все 88 сцен с
  обработанными замечаниями. Справа указано, что изменилось; стрелки перебирают
  только этот список. Ваши оценки и заметки сохранены для повторной сверки.
  Если заметка изменилась после исправления, стенд отдельно сообщает об этом.

Зелёные проверки справа подтверждают совпадение текста и ответов с базой.
Расположение объектов, условия приоритета и читаемость нужно оценивать по
двум изображениям: геометрия сцен создаётся вручную.

Стенд использует локально внедряемый `lab-hook.js`; его служебные API и
HTML-карточка не включаются в мобильное приложение.

При выключенной свободной камере доступны игровые жесты: во время вопроса
pinch или колесо приближают выбранную область, один палец или перетаскивание
мышью сдвигают кадр. После ответа масштаб и смещение сбрасываются. При
приближении во время езды камера наклоняется для обзора дороги вперёд.
Проверка жестов и дворовых выездов — `tools/game_tests/game-camera-courtyard-test.cjs`.

Проверка стенда: `node tools/game_tests/game-lab-review-test.cjs` с доступным Playwright
через `NODE_PATH`. Она перебирает весь активный каталог, сверяет исходники,
проверяет карточку и тему, а также единый цвет мокрого асфальта и нормали
дорожных полос.

Освещение мира и гаража зависит от сезона и погоды, а не от темы UI.
Плавный изгиб пока включён в 15 · 3: дорога, разметка, встречный грузовик и
управление используют общую ось. Остальные сцены добавляются по исходным
картинкам, чтобы изгиб не менял условия билета. Проверка проезда и независимости
мира от темы — `node tools/game_tests/game-curved-road-test.cjs`.

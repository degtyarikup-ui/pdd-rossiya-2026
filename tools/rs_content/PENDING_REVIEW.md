# RS: 1 вопрос без подтверждённого ответа (на 2026-07-15)

## ⚠️ Если пересобираешь official_questions.json / questions_ab.json / topics_ab.json

`build_official_questions.py` берёт текст ответов из **сырого**
`master_dataset.json`, не из уже почищенных файлов в `assets/`. Значит любой
пересбор (например, чтобы добавить ответ на `posledice_0159` по инструкции
ниже) **сотрёт** правки из `fix_extraction_artifacts.py` (см. раздел
«Артефакты PDF-экстракции» ниже) — они не зашиты в сам пайплайн, потому что
часть багов чинится только по исходному PDF, которого сейчас нет в репо.

После любого пересбора **обязательно** прогнать:
```
python3 tools/rs_content/fix_extraction_artifacts.py
```
и затем повторно проверить `flutter test` / визуально пролистать «Testovi»
для категорий sig/vozila (там сосредоточены самые заметные артефакты).

## Артефакты PDF-экстракции (найдено и почищено 2026-07-26)

`extract_questions.py` даёт на выходе несколько классов брака, не пойманных
исходным `mup_lib.is_garbled` (тот ловит только полностью пустой/структурно
не тексту вопрос, не битые слова):

1. **Дублирование границы спана** — заголовок «Saobraćajni znak…» и т.п.
   рассыпается на «z znak», «prikaz zan» и т.п. (2-6 символов дублируются на
   стыке двух спанов). Затронуло ~30 вопросов категорий `sig`/`vozila`
   (нашёл руками, см. `MANUAL_FIX` в `fix_extraction_artifacts.py`); 14 из
   них **удалены** — у них ТАКЖЕ убит кроп картинки (см. ниже), восстановить
   без исходного PDF нельзя.
2. **Кроп картинки в сливер** — bbox рисунка на странице определился неверно
   (58-75 px по ширине вместо 150-500), в итоге видно небо/деревья/фасад
   вместо знака. 16 вопросов **удалены целиком** (текст+картинка), список —
   `REMOVE_IDS` в `fix_extraction_artifacts.py`. Итог: 1763 → 1747 вопросов.
3. **«Прилипшая» служебная нумерация** — мелкий постраничный номер (без
   которого `NUM_RE` его не отфильтровал, т.к. регэксп ждёт точку после
   цифры: `^(\d+)\.$`) вклинивается в середину предложения («…mora 129
   najviše:»). Почищено скриптом у ~257 вопросов (чистая механика: убрать
   голое число, если рядом нет единицы измерения/«brojem»/перечисления).
4. **Надстрочный «³» и «°» потеряли позицию** — «radna zapremina motora 3
   150 cm» → должно быть «150 cm³»; «ne može prelaziti 30 … 0 0» → «30° …
   15°». Починено точечно (11 + 1 вопрос).
5. **Сегментация «съела» вопрос с points=4** — `POINTS_RE` в
   `extract_questions.py` ловит только жирные цифры 1-3 как маркер конца
   вопроса (см. докстринг), поэтому вопрос с 4 баллами не получил своего
   якоря и его текст+варианты приклеились к ПРЕДЫДУЩЕМУ вопросу как лишние
   варианты ответа. Нашлось 4 таких склейки (`rs_vozaci_0106/0111/0112`,
   `rs_vozila_0209`) — обрезаны обратно до исходного (верно оценённого)
   вопроса; сама «проглоченная» пара вопросов о времени отдыха водителей и о
   тормозной системе **потеряна** (не восстановить без PDF — я не берусь
   сам определять правильный ответ на регуляторный факт без верификации).
   `POINTS_RE` расширен на `4` на будущее, если PDF когда-нибудь появится.

Источник появления таких PDF — недоступен из окружения (антибот на
`mup.gov.rs`, прямые `wps/wcm/connect/...` ссылки отдают 404 без сессии
портала); чинил всё вручную по смыслу + сверкой с чистыми вопросами того же
семейства в самой базе.

Официальная база MUP — 1764 вопроса. В приложении (`official_questions.json`) —
**1763** (99.94%): те, где два независимых прохода `rs_official_answers_workflow.js`
сошлись сами либо их развёл агент-судья.

## Что не попало

**`posledice_0159`** — единственный вопрос, где два прохода разошлись, а судья
не смог уверенно выбрать (вернул `unresolved`). По дизайну такие вопросы
исключаются, а не угадываются: точность важнее полноты.

Сам вопрос лежит в `pending_review_questions.json`.

Учитывая, что автоматика уже дважды на нём споткнулась, дешевле и надёжнее
свериться с официальным источником вручную (PDF категории «Posledice
nepoštovanja propisa» на `prezentacije.mup.gov.rs/usp/Vozacki ispit/`), чем
гонять третий прогон.

## Как добавить ответ вручную

Дописать в `tools/rs_content/confirmed_answers.json` элемент
`{"gid": "posledice_0159", "index": <0-based индекс верного варианта>, "source": "manual"}`
и пересобрать:

```
python3 tools/rs_content/build_official_questions.py \
  tools/rs_content/master_dataset.json \
  tools/rs_content/confirmed_answers.json \
  assets/countries/rs/questions/official_questions.json
python3 tools/rs_content/build_questions.py
```

## Файлы пайплайна (в репо, переживают очистку scratchpad)

- `confirmed_answers.json` — подтверждённые ответы `{gid, index, source}`.
- `pending_review_questions.json` — то, что ещё без ответа.

# Локальная проверка иллюстраций А/Б

Запуск: `python3 tools/image_review/server.py --open` → http://127.0.0.1:8960.
Только localhost. Не требует изменения приложения, Node или сервера в интернете.

Первичная подготовка (сеть нужна только здесь):

```sh
python3 -m venv output/image-review-venv
output/image-review-venv/bin/pip install requests Pillow
output/image-review-venv/bin/python tools/image_review/prepare.py
```

Источник сравнения согласован владельцем: копия экзаменационных иллюстраций
на Дроме, а не прямые оригиналы с сервера ГИБДД. Официальный каталог вернул
403, последующая загрузка PDF прерывалась по таймауту. Программа не выдаёт
копии за подтверждённые файлы ГИБДД. Сопоставление по билету и вопросу,
проверка текстов, SHA-256 и исходные адреса сохраняются в манифесте.
Все 40 билетов разбираются отдельно; вопросы без картинок нашей базы исключены.

- ←/→: листать; пробел: отметить / снять; Enter: в порядке и дальше.
- Фильтры по билету и статусу. Переход: `12-5`, затем Enter.
- Клик на картинке: увеличение; Escape: закрытие.
- Отметки и заметки: `output/image-review/review.sqlite3` — сохраняемый файл,
  **не удалять при чистке output**. Позиция просмотра хранится в браузере.
- Кэш и манифест: `output/image-review/`. После подготовки можно работать офлайн.
- Выгрузка создаёт новую папку `~/Desktop/ПДД АБ — оригиналы <дата-время>/`.
  В ней только отмеченные эталоны и `Источники.json`; наши изображения
  не копируются и не изменяются. Файлы именуются по билету и вопросу.
- Если хотя бы один отмеченный эталон отсутствует, выгрузка целиком отклоняется.
- Повторная подготовка возобновляет скачивание из кэша и сохраняет отметки.

Проверки: `python3 -m unittest discover -s tools/image_review -p 'test_*.py'`.

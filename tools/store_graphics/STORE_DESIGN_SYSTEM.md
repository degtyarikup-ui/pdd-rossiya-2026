Документ фиксирует правила дизайна промо-скриншотов, типографики, цветовой палитры и текстов для обновления и перегенерации материалов при последующих релизах.

`tools/store_graphics/appstore_cards.cjs` перекомпоновывает те же восемь карточек
из исходных кадров (не растягивает готовые Android-постеры):

- iPhone с Dynamic Island, средний: 1179×2556, восемь файлов — загружены.
- iPhone с Face ID, большой: 1242×2688, резервный экспорт. В кабинете остальные
  размеры наследуют текущий набор среднего Dynamic Island.
- iPad 13″: 2048×2732, три игровые карточки — загружены. Для них отдельно снят
  Godot в окне 1536×2048 с теми же настоящими сценами; UI не перерисован.

Экспорт: `cards-v2/app-store/` — HTML-галерея, ZIP, исходники широких кадров,
манифест и SHA-256. Команда: `NODE_PATH=<bundled node_modules> node tools/store_graphics/appstore_cards.cjs`. Метаданные версии и загрузки сборки —
`store_assets/release-2026-10-18/appstore-{metadata,build}.json`.

## 1. Правила геометрии и верстки промо-скриншотов

```
+-------------------------------------------------------------+
|                                                             |
|                      [  БЕЙДЖ / ПЛАШКА  ]                   | Y = 120px, H = 56px
|                                                             |
|                       Заголовок в 2 строки                  | 92pt Onest-Bold
|                       с заглавной буквы                     | Y = 216px, LineHeight = 108px
|                                                             |
|      +-----------------------------------------------+      |
|      |                                               |      |
|      |                                               |      |
| 140px|               СКРИНШОТ ЭКРАНА                 |140px | Ширина: 800px
|      |              (Скругление 64px)                |      | Высота: 1777px
|      |                                               |      |
|      |                                               |      |
|      +-----------------------------------------------+      |
|                                                             |
|                           140px                             | Отступ снизу = боковым полям
+-------------------------------------------------------------+
```

### 1.1. Базовые параметры холста
* **Разрешение**: `1080 × 2400 px` (соотношение 9:20 / 9:16).
* **Формат файлов**: `.png` (RGB, quality $\ge$ 95).

### 1.2. Цветовая палитра фона (Brand Solid Colors)
> [!IMPORTANT]
> Никаких градиентов и чисто черного фона. Используются яркие, контрастные сплошные цвета из дизайн-системы приложения (`AppColors`):
* 🔵 **Основной синий** (`#0574F8` / `RGB(5, 116, 248)`) — для карточек с Лентой, Озвучкой и Билетами.
* 🟢 **Изумрудно-зеленый** (`#34A853` / `RGB(52, 168, 83)`) — для карточек с Экзаменом ГАИ и Шкалой готовности.
* 🟠 **Янтарно-оранжевый** (`#EB8214` / `RGB(235, 130, 20)`) — для карточек с Дорожными знаками, Разметкой и Штрафами.

### 1.3. Верхняя плашка (Pill Badge)
* **Форма**: белая сплошная капсула (`#FFFFFF`) со скруглением `R = 28px`.
* **Высота**: строго фиксированная `56px`.
* **Позиция по вертикали**: строго фиксированная `Y = 120px` на всех скриншотах.
* **Шрифт**: `28pt Onest-Bold` (верхний регистр). Цвет текста равен цвету фона карточки.
* **Оптическое центрирование**: текст центрируется по оптической оси прописных букв шрифта *Onest* (`draw_y = PILL_Y + (PILL_HEIGHT // 2) - 18px`).
* **Поля**: горизонтальный внутренний отступ `32px` с каждой стороны (`pill_width = text_width + 64px`).
* **Запрет эмодзи**: эмодзи не используются (чтобы избежать битых глифов и перегрузки).

### 1.4. Заголовки (Headlines)
* **Шрифт**: `92pt Onest-Bold`, цвет — белый (`#FFFFFF`).
* **Формат**: строго в **2 строки**, регистр Sentence case (с заглавной буквы, без капса).
* **Интервал**: межстрочный отступ `108px`.
* **Позиция**: начинается с `Y = 216px`, выравнивание по центру холста.
* **Без подзаголовков**: мелкий текст не добавляется.

### 1.5. Скриншот приложения (Mockup Placement)
* **Без рамок телефона**: убраны любые искусственные корпуса, динамики и фальшивые рамки.
* **Ширина**: `800px`.
* **Скругление углов**: `64px`.
* **Симметричные поля**: отступ слева (`140px`), справа (`140px`) и **снизу (`140px`)** строго одинаковы.
* **Тени**: **0px** (полное отсутствие теней для чистого плоского вида).

## 3. Скрипт генерации (Automation Tool)

Скрипт генерации сохранен в `tools/store_graphics/generate_screenshots.py`.

### Запуск генератора:
```bash
python3 tools/store_graphics/generate_screenshots.py
```
Скрипт автоматически берет скриншоты из папки, применяет оптическое выравнивание, рассчитывает симметрию полей и сохраняет готовые карточки в `store_assets/screenshots/` и на рабочий стол в `~/Desktop/PDD_Release_v.../Screenshots/`.

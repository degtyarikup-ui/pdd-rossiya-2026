# Картинки достижений

Значки достижений на Профиле — `assets/images/achievements/<id>_<level>.png`.
Сейчас там заглушки (`make_placeholders.py`). Настоящие картинки кладутся
поверх **под теми же именами**, код менять не нужно.

## Требования к файлу

- PNG 512×512, прозрачный фон, значок занимает ~90% кадра по центру.
- Только цветная версия: «не получено» приложение само делает серой и бледной.
- Число и подпись на значке должны совпадать с порогом из таблицы — их
  проверяет человек, а не код.
- У каждого достижения своя форма и символ (в заглушках: серия — щит с огнём,
  эрудит — круг с книгой, билеты — билет, неутомимый — шестиугольник с молнией,
  экзаменатор — восьмиугольник с шапочкой, без ошибок — розетка со звездой,
  работа над ошибками — квадрат с галочкой, гонщик — пятиугольник с рулём).
  Металл по уровню: 1 бронза, 2 серебро, 3 золото, 4 платина.

## Файлы (9 × 4 = 36)

| id | Достижение | Уровни 1 / 2 / 3 / 4 |
|---|---|---|
| `streak` | Без пропусков | 3 дня / 7 дней / 14 дней / 30 дней |
| `coverage` | Эрудит | 100 / 300 / 500 / 800 вопросов |
| `tickets` | Билет за билетом | 1 билет / 10 / 20 / 40 билетов |
| `attempts` | Неутомимый | 100 / 500 / 1000 / 3000 ответов |
| `exams` | Экзаменатор | 1 экзамен / 3 экзамена / 5 / 10 экзаменов |
| `flawless` | Без единой ошибки | 1 / 3 / 5 / 10 без ошибок |
| `mistakes` | Работа над ошибками | 10 / 50 / 100 / 200 исправлено |
| `game` | Гонщик | 1000 / 2500 / 5000 / 7500 очков |
| `rank` | Покоритель рейтинга | топ-100 / топ-10 / топ-3 / 1 место в недельном рейтинге (кубок, десятиугольник) |

Имя файла: `<id>_<уровень>.png`, например `streak_1.png`, `game_4.png`.
Пороги живут в `lib/data/models/achievement.dart`; поменяли их — поправьте
таблицу, `BADGES` в `make_placeholders.py` и сами картинки.

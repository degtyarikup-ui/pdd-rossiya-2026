## Почему я остановился
1. **Загрузка билда (72 МБ).** RuStore принимает файл только через выбор файла в браузере.
   Расширение, через которое я работаю, не загружает файлы больше 10 МБ, а системное
   окно выбора файла в Chrome мне недоступно. API RuStore из моей песочницы заблокирован.
2. **Ключ подписи.** Для AAB RuStore просит загрузить твой приватный ключ подписи и пароли.
   Из соображений безопасности мне нельзя вводить пароли/ключи в формы — это должен сделать ты.

## Шаг 1. Загрузить версию
Открой: console.rustore.ru/apps/2063722239 → **Версии** → **Загрузить версию**.

Самый простой вариант — загрузи готовый **AAB**:
- Файл: `build/app/outputs/bundle/release/app-release.aab`
- Когда попросит **Upload Signing Key** — загрузи keystore:
  - keystore: `android/upload-keystore.jks`
  - alias / пароли: в файле `android/key.properties` (keyAlias = upload)

(Альтернатива без загрузки ключа: собери APK командой `flutter build apk --release`
и загрузи `build/app/outputs/flutter-apk/app-release.apk` — APK уже подписан, ключ грузить не нужно.)

## Шаг 2. Заполнить карточку (тексты готовы)

- Категория: **Образование**. Возраст: **0+/3+**.

- Скриншоты: ссылки в `screenshot_urls.txt` (открой каждую → «Сохранить картинку»),
  либо возьми из своей страницы Google Play.
- Политика конфиденциальности: ссылка есть в `rustore_listing.md`.
- Комментарий модератору: можно оставить пустым (вход без регистрации, гостевой режим).

На рабочем столе теперь лежат:
- `pdd_2026.aab` — сам билд (72 МБ)
- `upload-keystore.jks` — ключ подписи
- `key.properties` — там пароли: storePassword и keyPassword = **Mojomaker-21**, alias = **upload**

## ⭐ САМЫЙ ПРОСТОЙ ПУТЬ (рекомендую) — загрузить APK, без возни с ключом

Если загрузить **APK** вместо AAB, окно «Загрузка ключа подписи» не нужно вообще
(APK уже подписан). Один файл — одна загрузка.

1. Открой Терминал, выполни:
   ```
   cd /Users/sergei/Documents/pdd
   flutter build apk --release
   ```
2. Готовый файл: `build/app/outputs/flutter-apk/app-release.apk`
3. В RuStore на странице «Upload app version» → нажми **Отмена** в окне ключа подписи →
   в блоке «APK-файлы или AAB-файлы» загрузи этот **app-release.apk**.
4. Дальше — заполнение карточки (тексты в `rustore_listing.md`).

## Путь через AAB + PEPK (если хочешь грузить именно AAB)

В открытом окне «Загрузка ключа подписи для AAB» 4 шага:

**Шаг 1.** Нажми «Скачать» — скачается `pepk.jar` (в папку Загрузки).

**Шаг 2.** Нажми «Копия» (скопируется команда RuStore с их ключом шифрования).
Открой Терминал и выполни (подставь пути к файлам на рабочем столе):
```
cd ~/Downloads
java -jar pepk.jar \
  --keystore=/Users/sergei/Desktop/upload-keystore.jks \
  --alias=upload \
  --output=/Users/sergei/Desktop/pepk_out.zip \
  <<--rsa-aes-encryption и --encryption-key-path из скопированной команды RuStore>>
```
Когда спросит пароли хранилища и ключа — введи **Mojomaker-21**.
Получится файл `pepk_out.zip` на рабочем столе.

> Важно: блок про шифрование (`--rsa-aes-encryption ...` или `--encryptionkey=...`)
> возьми ИЗ кнопки «Копия» в окне RuStore — он у каждого свой.

**Шаг 3.** Загрузи `pepk_out.zip` (≤100 КБ) в блок «Загрузите сгенерированный ZIP-архив».

**Шаг 4.** Сгенерируй загрузочный сертификат (PEM). В Терминале:
```
keytool -export -rfc -alias upload \
  -keystore /Users/sergei/Desktop/upload-keystore.jks \
  -file /Users/sergei/Desktop/upload_certificate.pem
```
Пароль — **Mojomaker-21**. Загрузи `upload_certificate.pem` в блок
«Загрузите загрузочный сертификат».

Нажми «Отправить ключ подписи», затем вернись и загрузи `pdd_2026.aab`
в блок «APK-файлы или AAB-файлы».

> Если в Терминале «command not found: java» — JDK не установлен.
> Тогда проще пойти по пути с APK (см. выше) — там java не нужна.

## После загрузки файла — заполнение карточки
Мастер проведёт по шагам (стрелка вверху: Файлы → … → инфо → картинки → настройки).
Все тексты, категория, возраст, иконка и ссылки на скриншоты — в файле `rustore_listing.md`
и `icon_512.png` рядом. В конце — «Отправить на модерацию».

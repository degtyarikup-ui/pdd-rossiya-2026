# Threads: подключение и планирование постов

Раздел **Threads** в админке хранит очередь постов, расставляет их по датам и
публикует сам — крон проверяет расписание каждые пять минут.

Публикация идёт по официальному Threads API: сначала создаётся «контейнер» с
текстом, через полминуты он публикуется. Токен продлевается автоматически раз
в 30 дней (живёт 60).

---

## Подключение (один раз, ~5 минут)

Приложение Meta то же самое, что для Instagram — **PDD** (id 3001923250171602).

1. **Принять приглашение тестировщика.** В кабинете роль уже назначена, но её
   нужно подтвердить со стороны Threads:
   <https://www.threads.net/settings/website_permissions> → раздел
   «Приглашения тестировщика» → **Принять**.
   Пока не принято, кабинет показывает статус «На рассмотрении», а токен не
   выдаётся.

2. **Добавить разрешения.** Сценарий использования **Threads API** →
   «Разрешения и функции»:
   - `threads_basic` — обязательное;
   - `threads_content_publish` — именно оно даёт право публиковать.

3. **Сгенерировать токен.** Там же, в настройке Threads API → «Сгенерируйте
   маркеры доступа» → выбрать аккаунт → скопировать строку.

4. **Вставить в админку.** Раздел «Threads» → **Подключение** → поле «Токен
   Threads» → «Сохранить». Id и имя аккаунта определятся сами — в тосте
   появится `@имя`. Дальше «Проверить».

## Как пользоваться

| Кнопка | Что делает |
|---|---|
| **Добавить посты** | вставляешь текст пачкой: один пост — один абзац, между постами пустая строка |
| **Расставить по датам** | раскидывает всю очередь по дням от завтрашней даты в заданное время |
| **Дата и время** (для выбранных) | своя дата старта, интервал и время |
| **Опубликовать сейчас** | публикует выбранные, не больше трёх за раз |
| **Уже опубликован** | помечает пост, не публикуя — если выложил вручную |

Текст поста правится прямо в списке, дата — полем рядом. Ограничение Threads —
500 знаков, счётчик показан над каждым постом.

## Ограничения, о которых стоит знать

- **Один пост за проверку расписания.** Крон публикует ближайший подошедший
  пост раз в пять минут: так лента не забивается пачкой сразу.
- **Между созданием и публикацией — 30 секунд.** Meta требует паузы, чтобы
  контейнер дозрел; поэтому кнопка «Опубликовать» отвечает не мгновенно.
- **Картинки** поддерживаются только по прямой ссылке (`imageUrl`), файлы
  Threads API не принимает.

## Где что в коде

| Файл | Назначение |
|---|---|
| `threads.js` | публикация, очередь, расписание, админ-API |
| `threads_ui.js` | раздел админки (разметка и скрипт) |
| `worker.js` | маршруты `/api/admin/threads/*` и вызов расписания из крона |

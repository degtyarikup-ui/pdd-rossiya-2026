# Одноразовые скрипты (архив)

Здесь лежит то, что уже отработало и в рабочем цикле не участвует.

- `*_worker.py`, `patch_*.py`, `fix_*.py`, `update_*.py`, `build_*admin*.py`,
  `retheme_admin.py` — разовые патчи `worker.js` и разметки админки. Панель
  собрана экранированными строками внутри `worker.js`, и каждая правка когда-то
  делалась таким скриптом. **Повторно их запускать нельзя** — они рассчитаны на
  то состояние файла, которое было на момент написания.
- `flow_experiments/` — попытки генерировать картинки через Flow, к воркеру
  отношения не имеют.

Новые правки раздела «Автопостинг» делаются в `social.js` / `social_ui.js` —
обычных модулях, которые подключаются к воркеру импортом.

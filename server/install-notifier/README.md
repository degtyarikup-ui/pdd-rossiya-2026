# pdd-install-notifier

Cloudflare Worker: приложение шлёт сюда событие о новой установке, воркер
пересылает его в Telegram-чат. **Токен бота живёт только здесь**, в приложение
не попадает. Хостинг бесплатный (Cloudflare free tier — 100k запросов/день).

## Что понадобится

- Токен бота от **@BotFather** (уже есть у тебя).
- **CHAT_ID** чата/группы, куда слать. Как узнать: добавь в свой чат бота
  **@getidsbot** (или **@RawDataBot**) — он пришлёт `chat id`. Для групп id
  начинается с `-100...`.

## Самый простой способ — один скрипт

Открой Терминал и вставь одну строку:

```bash
bash server/install-notifier/deploy.sh
```

Скрипт сам поставит инструмент, создаст хранилище для номеров и опубликует воркер.
От тебя: нажать «Allow» в браузере и вставить токен бота + id чата, когда попросит.
В конце он напечатает URL воркера.

Ниже — то же самое вручную, если хочется контролировать каждый шаг.

## Деплой (один раз, ~5 минут)

```bash
# 1. Установить wrangler (нужен Node.js)
npm install -g wrangler

# 2. Войти в Cloudflare (откроется браузер, аккаунт бесплатный)
wrangler login

# 3. Задать секреты (значения не коммитятся, хранятся в Cloudflare)
cd server/install-notifier
wrangler secret put BOT_TOKEN       # вставить токен от @BotFather
wrangler secret put CHAT_ID         # id чата (напр. -1001234567890)
wrangler secret put ADMIN_PASSWORD  # пароль для входа в веб-админку /admin
wrangler secret put SHARED_SECRET   # ключ приложения (см. ниже) — обязателен

# 4. (для номера «Пользователь #N») создать KV-хранилище
wrangler kv namespace create INSTALLS
#   → напечатает id; вставить его в wrangler.toml и раскомментировать
#     блок [[kv_namespaces]] (см. комментарий в файле).
#   Без этого шага воркер работает, но вместо #N показывает install_id.

# 5. Задеплоить
wrangler deploy
```

## Веб-админка и аналитика соцсетей

После деплоя доступна панель аналитики:
```
https://pdd-install-notifier.<твой-субдомен>.workers.dev/admin
```

- **Пароль**: только значение секрета `ADMIN_PASSWORD` (`wrangler secret put ADMIN_PASSWORD`).
  Паролей по умолчанию нет: пока секрет не задан, вход закрыт для всех — исходник
  воркера лежит в публичном репозитории, и зашитый в код пароль равносилен
  открытой админке. Вход защищён от перебора (8 попыток с адреса на 15 минут),
  в куке хранится случайный токен сессии, а не пароль.
- **Метрики**: Просмотры сайта, клики по кнопкам сторов (RuStore, Google Play, App Store, Веб), новые установки и CTR / CR конверсии.
- **Соцсети**: Статистика по YouTube, TikTok, Instagram, Telegram, VK и кампаниям.
- **Генератор ссылок**: Встроен в админку — создание размеченных ссылок для Shorts, Reels, Bio в 1 клик.
- **Live Feed**: Лента переходов и установок в реальном времени.
- **Автопостинг**: Раздел публикует ролики в Instagram Reels и YouTube Shorts
  по расписанию — папка на Google Диске → очередь → один ролик в день.
  Настройка доступов и подробности — в [SOCIAL_SETUP.md](SOCIAL_SETUP.md).

Команда `wrangler deploy` в конце напечатает URL вида:

```
https://pdd-install-notifier.<твой-субдомен>.workers.dev
```

## Что где лежит

- `worker.js` — сам воркер. Разметка админки внутри него собрана экранированными
  строками: руками её не правят, раздел «Автопостинг» подключается модулями
  `social.js` / `social_ui.js`.
- `legacy/` — архив одноразовых патчей воркера и админки. Не запускать: они
  рассчитаны на то состояние файла, которое было на момент написания.
- `test-local.mjs`, `test-admin-local.mjs` — прогон воркера без деплоя
  (`node test-admin-local.mjs`).

## Ключ приложения (SHARED_SECRET)

Разбор вопросов от ИИ работает через наш ключ Gemini, то есть за наши деньги.
Чтобы эндпоинт `/api/ai/chat` не превратился в бесплатный доступ к нейросети
для посторонних, приложение подписывает запросы заголовком `x-install-secret`.

- Значение лежит в `secrets/install_notify_secret.txt` (папка в `.gitignore`)
  и в секрете воркера `SHARED_SECRET`. `scripts/build.sh` подставляет его в
  сборку сам — отдельно ничего экспортировать не нужно.
- Свободный чат с ИИ доступен **только** подписанным запросам.
- Версии, выпущенные до появления ключа, подписывать нечем, поэтому им оставлен
  узкий проход: разбор конкретного вопроса, без чата, не более 40 запросов в
  сутки с адреса. Когда обновление разойдётся по магазинам — сними галочку
  «Пускать приложения без ключа» в разделе «Управление ИИ», и проход закроется.
- Тот же ключ защищает пинги об установках и жалобы на вопросы: присланный
  неверный ключ отвергается сразу.

⚠️ Если потерять `secrets/install_notify_secret.txt`, новые сборки перестанут
проходить проверку — тогда задай `SHARED_SECRET` заново и пересобери приложение.

## Подключить к приложению

**Способ 1 (рекомендуется)** — через переменные окружения, ничего не хардкодится
и не попадает в git. `scripts/build.sh` сам подставит их в сборку:

```bash
export INSTALL_NOTIFY_URL=https://pdd-install-notifier.<субдомен>.workers.dev
export INSTALL_NOTIFY_SECRET=<строка>   # только если задавал SHARED_SECRET
./scripts/build.sh ru aab
```

**Способ 2** — вписать URL прямо в код: заменить `PASTE_WORKER_URL_HERE` в поле
`defaultValue` в `lib/data/services/install_reporter.dart`.

Если ни то, ни другое не задано — фича «спит» (приложение ничего не шлёт).

## Посмотреть, как выглядит сообщение (без деплоя)

```bash
node server/install-notifier/test-local.mjs
```

## Проверить, что работает

```bash
curl -X POST https://pdd-install-notifier.<твой-субдомен>.workers.dev \
  -H 'content-type: application/json' \
  -H 'x-install-secret: <SHARED_SECRET, если задавал>' \
  -d '{"country":"ru","app":"ПДД Россия 2026","device":"Test Phone","os":"Android 14","platform":"android","version":"1.0.5+16","locale":"ru-RU","install_id":"deadbeef"}'
```

→ в чате должно появиться сообщение «🆕 Новая установка».

## Кого трекаем

Только новых пользователей. Клиент по-прежнему шлёт `kind: 'new'|'update'`
(update — юзер, у которого уже были данные приложения до этой фичи), но воркер
события с `kind='update'` молча игнорирует: не занимают номер, не попадают в
статистику/чат. Клиент получает 2xx и просто больше не повторяет запрос.

## Что в сообщении

`🆕 Новая установка` / `🔄 Обновился` · `👤 #N` · `🏬 источник` · устройство · ОС ·
версия · язык · время. **Источник** определяется по магазину-установщику:
Google Play, RuStore, App Store, TestFlight, Web и т.п. (на sideload/APK —
«Sideload/неизвестно»).

## Ежемесячная сводка

Cron-триггер `0 6 1 * *` (1-го числа, 09:00 МСК) шлёт итоги прошедшего месяца:
сколько новых установок, обновившихся, всего и **разбивку по источникам**
(Google Play / RuStore / Web / …). Считается по помесячным ключам в KV
(`m:YYYY-MM:total|new|upd` и `m:YYYY-MM:src:<источник>`). Регистрируется
автоматически при `wrangler deploy`.

## Как приложение защищено от кражи токена

Токен бота хранится в секрете воркера и в APK не попадает — из установленного
приложения его вытащить нельзя. `SHARED_SECRET` — необязательный дополнительный
барьер против постороннего спама на эндпоинт (в клиенте он всё же присутствует,
поэтому это защита «от случайных», а не «от целевого» злоупотребления).

# Автопостинг в Instagram Reels и YouTube Shorts

Раздел **«Автопостинг»** в админке (`/admin`) сам публикует ролики:
папка на Google Диске → очередь → раз в день в заданное время ролик уходит
в Instagram и на YouTube.

Схема повторяет ту, что работает в админке Meerno, но целиком живёт в
Cloudflare Worker: у него нет диска, поэтому Instagram скачивает видео по
временной ссылке `/s/v/<токен>` (воркер проксирует её с Диска), а на YouTube
воркер заливает файл сам.

Ниже — что нужно сделать один раз. Всё бесплатно.

---

## Шаг 1. Доступ к Google (Диск + YouTube)

Один доступ обслуживает и папку с роликами, и канал.

1. Открой <https://console.cloud.google.com/> и создай проект (или возьми
   существующий проект ПДД).
2. **APIs & Services → Library**: включи два API —
   **Google Drive API** и **YouTube Data API v3**.
3. **APIs & Services → OAuth consent screen**:
   - тип **External**, название любое («ПДД автопостинг»);
   - добавь себя в **Test users**;
   - ⚠️ после настройки нажми **PUBLISH APP** (статус «In production»).
     Это важно: в статусе «Testing» Google отзывает refresh token через
     **7 дней**, и автопостинг молча перестанет работать. Проверку Google
     проходить не нужно — предупреждение «приложение не проверено» на своём же
     аккаунте просто пропускается.
4. **APIs & Services → Credentials → Create credentials → OAuth client ID**,
   тип **Desktop app**. Скопируй **Client ID** и **Client Secret**.
5. Скачай файл ключа кнопкой «Download JSON» — он попадёт в `~/Downloads`.
6. Одна команда — она подхватит этот файл, откроет вход в Google, получит
   доступ и сама впишет его в админку:

   ```bash
   python3 /Users/sergei/Documents/pdd/server/install-notifier/setup_google.py
   ```

   В браузере выбери аккаунт с папкой роликов и каналом; на «приложение не
   проверено» — «Дополнительные настройки» → «Перейти».

7. Если что-то пошло не так, значения всегда можно вписать руками:
   админка → **Автопостинг → Шаг 1** → **Сохранить** → **Проверить подключение**.

**Квота YouTube:** одна заливка стоит 1600 единиц из 10 000 в сутки — это
до 6 роликов в день. Нам хватает: публикуем один.

## Шаг 2. Instagram

Постить может только **профессиональный** аккаунт (Business или Creator):
в приложении Instagram → «Настройки» → «Тип аккаунта» → «Переключиться на
профессиональный».

Дальше — в кабинете <https://developers.facebook.com/apps/>, сценарий
использования **Instagram API с Instagram Login**:

1. **Разрешения и функции.** Кнопка «Add all required permissions» добавляет
   только разрешения для сообщений и комментариев — их мало. Нужно вручную
   найти и добавить **`instagram_business_content_publish`**: именно оно даёт
   право публиковать. Без него публикация будет падать с ошибкой доступа.
   Второе обязательное — `instagram_business_basic` (оно в списке есть).
   Разрешения для сообщений (`manage_messages`, `manage_comments`) нам не
   нужны — можно не добавлять.
2. **Роли → Instagram tester.** Добавь свой Instagram-аккаунт тестировщиком,
   затем прими приглашение в самом Instagram: «Настройки» → «Приложения и
   сайты» → «Приглашения тестировщика».
3. **Сгенерируйте маркеры доступа → «Добавить аккаунт».** Войди своим
   Instagram-аккаунтом, разреши доступ — появится маркер (токен). Скопируй его.
4. **Webhooks (пункт 3 на экране) — пропускаем.** Они нужны для входящих
   сообщений, к публикации отношения не имеют.
5. В админке → «Автопостинг» → «Добавить аккаунт»: вставь токен в поле
   «Instagram токен». **Поле «Instagram Account ID» оставь пустым** — панель
   сама спросит номер у Meta и подставит; в тосте появится имя аккаунта.

Публиковать в свой же аккаунт можно, пока приложение в режиме разработки —
проверку Meta проходить не нужно.

Токен живёт 60 дней, воркер продлевает его сам раз в 30 дней. Если продлить не
удалось — запись появится в журнале раздела.

## Шаг 3. Папка с роликами на Google Диске

1. Создай на Диске папку, например «ПДД — ролики».
2. Открой её и скопируй адрес из строки браузера — в админку можно вставить
   ссылку целиком, ID вытащится сам.
3. Складывай туда готовые вертикальные ролики (`.mp4`, до 90 МБ).
   - Порядок публикации — по имени файла, поэтому удобно нумеровать:
     `001_…`, `002_…`.
   - Подпись можно задать рядом: файл `001_znak.txt` станет подписью к
     `001_znak.mp4`. Если .txt нет — берётся шаблон подписи из настроек
     аккаунта (`{title}` подставит название ролика).

Открывать папку «по ссылке для всех» не нужно: воркер читает её по доступу
из шага 1.

## Шаг 4. Расписание

В настройках аккаунта задаётся время публикации по МСК. Крон воркера
просыпается каждый час и публикует **один ролик в день** в свой слот
(если слот пропущен из-за сбоя — подхватит в течение трёх часов).

Кнопки в разделе:

| Кнопка | Что делает |
|---|---|
| **Забрать с Диска** | смотрит папку и добавляет новые ролики в очередь |
| **Опубликовать сейчас** | публикует конкретный ролик, не дожидаясь слота |
| **Повторить** | у упавшего ролика дозаливает только ту площадку, куда он не ушёл (дубля не будет) |
| **Проверить расписание** | прогоняет то, что делает крон, прямо сейчас |
| **Проверить подключение** | показывает, живы ли доступы к Google, Диску, Instagram и YouTube |

Об упавшей автопубликации приходит сообщение в тот же Telegram-чат, куда
воркер шлёт отчёты об установках.

## Что где лежит в коде

| Файл | Назначение |
|---|---|
| `social.js` | вся логика: Диск, очередь, Instagram, YouTube, крон, админ-API |
| `social_ui.js` | раздел «Автопостинг» в админке (разметка + скрипт) |
| `worker.js` | маршруты `/api/admin/social/*`, `/s/v/<токен>` и часовой крон |
| `get_google_token.py` | получение refresh token Google |

Деплой после правок — как обычно:

```bash
npx wrangler deploy
```

## Ограничения, о которых стоит знать

- **Размер ролика — до 90 МБ.** На YouTube файл заливается из памяти воркера
  (лимит инстанса 128 МБ). Ролики «Успей узнать знак» весят единицы мегабайт,
  запас большой, но при превышении в очереди появится понятная ошибка.
- **Instagram кодирует видео у себя** — публикация занимает до 3-4 минут.
  Панель в это время показывает «Публикуется…» и сама обновляет статус.
- **Один ролик в день на аккаунт.** Нужно чаще — заводится второй аккаунт
  с другим временем публикации либо публикуется вручную кнопкой.

# Общий интерфейс

Пакет используется приложениями стран. Сейчас содержит только неизменённые
дизайн-токены российского приложения. Не добавлять зависимости на `pdd_app`,
`apps/`, CountryConfig, серверы, покупки, строки или контент страны.
Никаких изображений, аудио, шрифтов и игровых архивов в этом пакете.
Новый общий компонент выносить только при подтверждённом переиспользовании.
Старые импорты России остаются совместимыми через export-файлы.
После изменений — анализатор и все тесты каждого приложения-потребителя.
